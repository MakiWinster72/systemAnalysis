## 简介

基于 Obsidian 构建的**系统分析师**（软考高级）备考知识库。涵盖教材知识点、概念卡片、真题案例与原始资料，利用 obsidian 双向连接的能力快速/辅助自己学习相关知识点。

## 目录结构

```
.
├── 知识点/          # 核心知识卡片（在x赛最后那个视频里面找的核心知识点）
├── 练习/
│   └── 案例题/
├── wiki/            # Kaparthy 知识管理结构
│   ├── concepts/    # 核心概念定义
│   ├── sources/     # 原始资料（这个没传，平时一般也不打开）
│   └── summaries/   # 各章节专题总结
├── raw/             # 317 份教材 PDF 切片(好像是有些章节切分不对或丢失的)
├── assets/          # 视频与静态资源
└── 教材章节结构.md  # 完整教材目录索引
```

## 内容体系

## 使用方法

1. **Obsidian 打开本库**然后浏览 wiki/summaries 按章节学习
2. **配合 raw/ 原始教材** — 每个知识点对应一份 PDF 切片，深入理解
   做题的话可以考虑用 openclaw / hermes 整理题目并且产生对应知识点的双向链接，如果只是查询相关知识点或者理论，用claudian就可以了。
