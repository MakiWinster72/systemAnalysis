# 层叠样式表

**层叠样式表**（Cascading Style Sheets，简称 **CSS**）是由W3C定义和维护的标准，是一种用来为结构化文档（如HTML文档或XML应用）添加样式（字体、间距和颜色等）的计算机语言。

## 基本概念

一个Web页面的读者和作者都可以使用CSS来决定文件的颜色、字体、排版等显示特性。

## CSS的核心目的

CSS最主要的目的就是**将文件的结构与文件的显示分隔开来**。文件结构用HTML或其他相关语言编写，而显示效果由CSS控制。这种分离带来的好处包括：

- **维护性提升**：改变样式时无需修改HTML结构
- **重用性增强**：同一CSS可应用于多个页面
- **带宽节省**：减少重复的样式代码

## 扩展能力

CSS不仅可以用于传统的视觉显示，还可以使用其他的显示方式：

- **声音输出**：假如浏览器有阅读功能的话
- **辅助设备**：给盲人用的感受装置

## 兼容性

CSS可以与多种结构文件一起使用，唯一的条件是显示这种文件的浏览器能够接受CSS的功能：

- [[XHTML]]
- [[XML]]
- HTML文档
- 其他结构文件

## 在小程序中的应用：WXSS

CSS不仅是传统Web开发的标准样式语言，其设计理念也影响了**小程序开发**领域。在微信小程序中，使用 **WXSS**（WeiXin Style Sheets）作为样式表语言，其大部分语法与CSS基本相同。

类似地，在其他移动应用开发框架中，样式技术也大多基于或借鉴了CSS的设计思想，实现了跨平台样式定义的统一。

## 与其他技术的关系

CSS是[[DHTML]]（动态HTML）的重要组成部分，综合了JavaScript、VBScript、DOM、Layers等技术，实现Web页面在浏览器中的动态更新。

在[[AJAX]]技术中，CSS与JavaScript配合使用，当请求返回时，使用CSS来更新用户界面，而不是刷新整个页面。

## 技术定位

CSS是[[Web应用系统客户端技术]]中的基本开发技术之一，与[[HTML]]配合使用，共同实现Web页面的结构与表现分离。
