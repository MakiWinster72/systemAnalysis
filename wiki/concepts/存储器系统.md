# 存储器系统

## 定义

存储器（Memory/Storage）是用来存放程序和数据的部件，是计算机的记忆装置。存储器是计算机能够实现「存储程序控制」的基础，整个计算机系统的工作流程都依赖于存储器的数据存取。

## 存储层次结构

传统的存储器系统一般分为**三级**：

```
┌─────────────────────────────┐
│  高速缓冲存储器 (Cache)       │ ← 速度最快、容量最小
├─────────────────────────────┤
│  主存储器 (Main Memory)      │ ← 速度较快、容量中等
├─────────────────────────────┤
│  辅助存储器 (Auxiliary)      │ ← 速度较慢、容量最大
└─────────────────────────────┘
```

这种分层结构的设计理念是：**容量越大速度越慢，速度越快容量越小**。通过合理分配数据在不同层级的存储位置，可以兼顾性能和成本。

## 共享存储模型

在多处理机系统中，存储器系统根据访问方式的不同可分为多种共享存储模型：

### 1. UMA（均匀存储器存取）模型

**UMA（Uniform Memory Access）** 模型中，物理存储器被所有处理机均匀共享。所有处理机对存储器的访问时间和带宽是均匀的，处理机访问本地存储器和远程存储器的时间相同。这种模型常见于[[对称多处理机|SMP对称多处理机]]系统。

### 2. NUMA（非均匀存储器存取）模型

**NUMA（Nonuniform Memory Access）** 模型的访问时间随存储字的位置不同而变化。SM（共享存储器）物理上分布在所有处理机的LM（本地存储器）上，所有LM的集合组成了全局地址空间，可被所有处理机访问。处理机访问本地LM较快，但访问属于另一台处理机的远程存储器则较慢，因为通过互连网络会产生附加时延。

### 3. COMA（只用高速缓存的存储器结构）模型

**COMA（Cache Only Memory Architecture）** 模型是NUMA机的一种特例，是将NUMA中的分布主存储器换成了高速缓存。在每个处理机结点上没有存储器层次结构，全部高速缓冲存储器组成了全局地址空间。远程高速缓存访问则需要借助于分布高速缓存目录进行。

## 数据存取方式

存储器系统中数据常用的存取方式有**4种**：

| 存取方式 | 说明 | 典型设备 |
|----------|------|----------|
| **顺序存取** | 数据按顺序访问，后续访问位置依赖前一次位置 | 磁带存储器 |
| **直接存取** | 可直接定位到任意物理块，访问时间与位置无关 | 硬盘存储器 |
| **随机存取** | 任意位置访问时间相同，可随机读写 | RAM、主存 |
| **相联存取** | 按内容而非地址访问 | Cache |

## 主存与I/O系统的交互


存储器系统与[[输入输出系统]]（I/O系统）密切相关。在现代计算机体系结构中，主存储器不仅要被CPU访问，还需要与各种I/O设备进行数据交换。

### DMA工作方式

在高速、批量数据传输场景下，计算机会采用**DMA（直接存储器访问，Direct Memory Access）** 技术。DMA控制器（DMAC）与CPU共享系统总线，但具有独立访问存储器的能力。

DMA的工作方式使主存与CPU的固定联系脱钩：
- 主存既可被CPU访问，又可被外设访问
- 在数据块传送时，主存地址的确定、传送数据的计数等都由硬件电路直接实现
- 主存中需要开辟专用缓冲区，及时供给和接收外设的数据

DMA传送速度快，使CPU和外设能够并行工作，显著提高了系统效率。

### 主存缓冲区

在进行DMA传输前，需要通过程序进行预处理；传输结束后，需要通过中断方式进行后处理。主存中开辟的专用缓冲区用于临时存放I/O设备的数据，确保数据传输的连续性和正确性。

## 性能指标

存储器系统主要有**4个性能指标**：

1. **存取时间（Access Time）**：从启动访问到完成访问所需的时间
2. **存储器带宽（Bandwidth）**：单位时间内可传输的数据量
3. **存储器周期（Cycle Time）**：连续两次访问所需的最小间隔
4. **数据传输率（Transfer Rate）**：单位时间内从存储器读出或写入的数据量
