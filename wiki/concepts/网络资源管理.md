# 网络资源管理功能与系统概述

网络资源管理是指通过系统化方法对网络资源进行调整和控制，使网络能正常、高效地运行的管理活动。它是企业IT基础设施管理的核心内容，涵盖局站、机房、管道、光缆、电缆、传输设备、光/电路、交换、数据、动力、接入、时钟同步、基站等各类资源。

## 五大核心管理功能

网络资源管理主要包含以下五大功能，这些功能共同构成了[[summaries/15.2.2网络资源管理]]中描述的网络系统正常运行的基本保证：

### [[性能管理]]

性能管理是在使用最少的网络资源和具有最小延迟的前提下，确保网络能提供可靠、连续的通信能力，并使网络资源的使用达到最优化程度。该功能包含两大核心：
- **监测功能**：对网络中的活动进行跟踪
- **控制功能**：实施相应调整来提高网络性能

在局域网环境中，以太网作为占据主导地位的网络技术，其性能直接影响整体网络表现。以太网采用的[[CSMA/CD协议]]（带冲突检测的载波监听多路访问）是影响网络性能的重要因素。不同速率的以太网（如10Mb/s标准以太网、100Mb/s快速以太网、1000Mb/s千兆以太网）具有不同的介质访问特性和传输性能，在性能管理中需要针对这些特性进行监测和优化。

### [[故障管理]]

故障管理负责检测、定位和排除网络硬件和软件中的故障。当出现故障时，该功能执行以下步骤：
1. 确认故障发生
2. 记录故障详情
3. 找出故障位置
4. 尽可能排除故障

故障调查是故障管理流程中的关键环节，其核心目标是收集故障信息、确定故障位置和调查故障原因。故障信息收集方式主要分为两种：

- **自动收集**：系统本身具备故障信息收集功能，可通过系统监控工具或系统日志等方式进行自动收集
- **人工收集**：包括用户反馈（系统运行中出现的故障直接反映在用户端）以及IT部门在执行系统检查和维护时主动发现

在以太网环境中，冲突检测机制（"边发边听"）是故障检测的重要组成部分。当检测到冲突并发出阻塞信号后，系统采用退避算法（如二进制指数退避算法）来处理冲突，延长等待时间以降低再次冲突概率。这一机制与故障管理的冲突处理流程紧密相关，体现了网络资源管理在维护网络稳定性方面的作用。

### [[配置管理]]

配置管理旨在掌握和控制网络的状态，包括网络内各个设备的状态及其连接关系。典型方法包括：
- 用逻辑图描述所有网络设备及其逻辑关系
- 将网络的确切物理布局以适当比例映射到逻辑图
- 用精心设计的图标表示各种网络对象
- 用不同颜色表示设备的不同状态

以太网作为核心网络资源，在配置管理中需要详细记录其类型和规格。根据不同的IEEE标准，以太网可分为：
- **IEEE 802.3标准以太网**（10Mb/s）：传输介质为细同轴电缆
- **IEEE 802.3u快速以太网**（100Mb/s）：传输介质为双绞线，包括100Base-TX、100Base-FX、100Base-T4等变体
- **IEEE 802.3z千兆以太网**（1000Mb/s）：传输介质为光纤或双绞线

配置管理需记录这些网络资源的技术参数、物理拓扑和逻辑连接关系，支持基于地图方式的查询和统计分析，实现物理路由图和逻辑拓扑图的有效管理。

### [[计费管理]]

计费管理记录各用户和应用程序对网络资源的使用情况，提供计算一个特定网络或网段运行成本的手段，支持成本核算和资源分配决策。

### [[安全管理]]

安全管理对网络资源及其重要信息访问进行约束和控制，主要功能包括：
- 验证网络用户的访问权限和优先级
- 检测和记录未授权用户企图进行的不应有的操作

## 网络资源管理系统

资源管理系统的定位是管理网络资源数据和支持网络资源的设计与分配，具备以下核心能力：

| 功能类别 | 具体内容 |
|---------|----------|
| 数据管理 | 收集、分类、增删改、显示、存储和检索 |
| 数据质量 | 保证数据的完整性和一致性 |
| 应用支撑 | 支撑各类应用系统和网管系统开通电路 |
| 地图管理 | 基于地图方式的查询、统计分析 |
| 图型管理 | 物理路由图和逻辑拓扑图管理 |
| 关联管理 | 设备展开图、端子图等关联管理 |
| 调度管理 | 资源调度和割接管理 |
| 电路管理 | 光/电路由配置、信息查询功能 |
| 系统运行 | 数据维护、安全管理、数据备份与恢复、版本控制 |

## 与其他管理领域的关系

网络资源管理是系统运行与维护的重要组成部分，与[[系统运行与维护]]中的其他管理活动相互配合，共同保障企业信息系统的稳定运行。通过五大功能体系的协同运作，能够及时发现和处理网络故障，确保网络的可靠性和可用性。以太网作为局域网的核心技术，其CSMA/CD机制、冲突检测和退避算法等特性都是故障管理和性能管理中需要重点关注的内容。
