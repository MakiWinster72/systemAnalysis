# 显性知识（Explicit Knowledge）

显性知识是指能够以文字、符号与数字来表达的知识，它以资料、科学法则、特定规格及手册等形式展现。这种知识随时都可在个人之间相互传送，不受个体经验限制。

## 定义特征

显性知识具有以下核心特征：
- **可编码性**：能够用文字、数字、图表等符号系统完整表达
- **可传递性**：可通过文档、培训、交流等方式在个人间传播
- **可储存性**：能够被系统化地整理、归档和保存
- **可共享性**：不依赖特定个体，可被组织内成员广泛使用
- **规范化**：知识呈现规范、系统的形式，而非零星分散
- **科学性**：背后有科学和实证基础支撑
- **稳定性**：内容明确、不易随时间和情境变化

## 主要表现形式


- 资料文献（报告、论文、手册）
- 科学法则与公式
- 特定规格与标准
- 操作手册与技术文档
- 数据库中的结构化信息
- 规章制度与流程文档
- 用诀窍、习惯、信念、个人特技等形式呈现的[[隐性知识]]形成鲜明对比

## 与隐性知识的对比

| 显性知识 | [[隐性知识]] |
|---------|-------------|
| 规范、系统 | 尚未或难以规范、零星 |
| 背后有科学和实证基础 | 背后的科学原理不甚明确 |
| 稳定、明确 | 非正式、难以捉摸 |
| 经过编码、格式化、结构化 | 尚未编码、尚未格式化、尚未结构化 |
| 用公式、软件程序、规律、法则、原则和说明书等方式表述 | 用诀窍、习惯、信念、个人特技等形式呈现 |
| 运用者对所用知识有明确认识 | 运用者对所用知识可能不甚了解 |
| **易于储存、理解、沟通、分享、传递** | 不易保存、不易传递、不易掌握 |

显性知识的优势在于**易于储存、理解、沟通、分享和传递**，而隐性知识则需要通过更深层次的[[知识管理]]手段（如知识生成工具和知识转移工具）来实现其价值转化。有效的知识管理需要同时关注显性知识的整理激活与隐性知识的挖掘转化。

## 管理意义

在[[企业信息化]]背景下，显性知识的管理是构建组织知识库的基础。通过文档化、系统化的管理，企业可以最大化知识的复用价值，降低因人员流动带来的知识流失风险。

[[商业智能]]（Business Intelligence）的发展进一步凸显了显性知识的价值——通过[[数据仓库]]、数据抽取、OLAP等技术，将企业积累的显性数据转化为可决策支持的信息资产。
