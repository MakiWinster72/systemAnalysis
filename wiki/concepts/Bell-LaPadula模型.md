# Bell-LaPadula安全模型

## 概述

Bell-LaPadula（简称BLP）模型是计算机安全领域第一个正式的安全模型，于1973年由Elliot Bell和Leon LaPadula提出。该模型基于[[强制访问控制]]（MAC）系统，是典型的信息保密性多级安全模型，最初主要应用于军事系统中。

BLP模型的核心目标是**保障数据的机密度与敏感度**，通过形式化的方法描述安全系统的行为规则。

## 安全等级划分

BLP模型将数据和用户的安全等级划分为**五个级别**（从低到高）：

| 等级 | 说明 |
|------|------|
| 公开 | 最低安全级别，可被所有用户访问 |
| 受限 | 限制性访问资源 |
| 秘密 | 敏感但非机密信息 |
| 机密 | 重要敏感信息 |
| 高密 | 最高安全级别，仅限授权人员 |

## 核心安全规则

BLP模型基于两种基本规则来保障数据安全：

### 1. 上读规则（Simple Security Property / No Read Up）

> 主体不可读取安全级别高于它的数据。

用户只能读取**等于或低于**自身安全级别的资源，防止低级别用户获取高敏感信息。

### 2. 下写规则（Star Property / No Write Down）

> 主体不可写入安全级别低于它的数据。

用户只能写入**等于或高于**自身安全级别的资源，防止高敏感信息泄露到低安全级别。

## 示例说明

以安全级别「高密」用户访问「秘密」级别文件为例：

- **读取操作**：✓ 成功（高密 > 秘密，符合上读规则）
- **写入操作**：✗ 失败（高密 > 秘密，违反下写规则）

以安全级别「秘密」用户访问「高密」级别文件为例：

- **读取操作**：✗ 失败（秘密 < 高密，违反上读规则）
- **写入操作**：✓ 成功（秘密 < 高密，符合下写规则）

## 设计意义

BLP模型的「上读下写」规则确保了信息只能**向上流动**（写入更高级别）和**向下流动**（读取更低级别），有效防止了敏感信息的未授权泄露，保障了多级安全系统的保密性。
