# 代码重用

## 概念定义

代码重用是指对现有（已经写好的）代码进行复用，这些代码来自外部资源或过往项目，用以开发新软件，实现相同或相似的功能。这是提高软件开发效率的重要手段。

## 核心要点

### 代码重用的三个层次

软件重用可以分为三个层次：

1. **代码重用**：直接复用现有代码
2. **设计结果重用**：复用设计阶段产生的架构和设计方案
3. **分析结果重用**：复用分析阶段的成果

### 实现方法

常用的代码重用实现方法包括：

| 方法 | 描述 |
|------|------|
| **使用函数** | 将代码抽象成函数，在多个地方调用该函数即可 |
| **使用对象** | 将复杂代码封装成对象，便于重复使用 |
| **使用模块** | 抽象成独立模块，调用即可实现相同功能，提高程序可重用性 |
| **使用类** | 利用面向对象思想，通过继承和多态实现高度复用 |
| **利用算法** | 采用解构和分解组合算法减少代码重复使用的损耗 |

### 关键条件

代码重用并非适用于所有软件开发，需要满足以下条件：

- **高质量代码**：只有无错或不复杂的代码才能被重用
- **先分析后重用**：开发人员需要先分析应用程序的条件和要求
- **评估重用条件**：有必要先评估重用条件后再进行代码重用

## 相关概念

- [[concepts/软件质量]]：高质量的代码是代码重用的前提
- [[concepts/面向对象]]：继承和多态是实现高度代码复用的核心机制
- [[concepts/模块化]]：模块化设计是提高代码可重用性的重要方法
- [[summaries/14.2.1软件测试的概念]]：软件测试与代码质量密切相关，重用高质量代码有助于提高软件可靠性

## 应用价值

开发快速、可靠和安全的软件始终需要大量编程技能和知识。通过合理的代码重用策略，可以：

- 提高开发效率，减少重复劳动
- 降低开发成本
- 提高软件[[concepts/软件可靠性]]和[[concepts/软件质量]]
- 促进知识的积累和传承
