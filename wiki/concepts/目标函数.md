# 目标函数：线性规划的优化核心

## 定义

**目标函数**（Objective Function）是[[线性规划]]问题中用于表示优化目标的数学表达式，它决定了在满足所有[[约束条件]]的前提下，我们希望最大化或最小化的对象。

## 基本形式

在线性规划中，目标函数是一个线性函数，具有以下标准形式：

```
max z = c₁x₁ + c₂x₂ + ... + cₙxₙ
或
min z = c₁x₁ + c₂x₂ + ... + cₙxₙ
```

其中：
- **z**：目标值（要优化对象，如利润、成本、产量等）
- **cᵢ**：各[[决策变量]]的系数（表示单位贡献或成本）
- **xᵢ**：决策变量（表示各产品的产量、资源分配量等）

## 在决策中的作用

根据[[summaries/2.3.5决策的方法]]，目标函数在[[决策]]过程中承担核心角色：

1. **明确优化方向**：确定是最大化还是最小化目标
2. **量化评价标准**：将复杂的决策目标转化为可计算的数学表达式
3. **指导最优解搜索**：在[[可行域]]中寻找使目标函数达到最优值的点

## 实际应用示例

在[[summaries/2.3.5决策的方法]]中的工厂排产问题实例展示了目标函数的应用：

```
max z = 2x₁ + 3x₂
```

该目标函数表示：
- **z**：工厂利润
- **x₁**：产品Ⅰ的产量（每件利润2元）
- **x₂**：产品Ⅱ的产量（每件利润3元）
- 目标是使利润最大化

## 等值线与最优解

目标函数的一个重要特性是可以在坐标平面上表示为**等值线**（Isocline）：

- 位于同一直线上的所有点具有相同的目标函数值
- 当z值由小变大时，直线沿其法线方向移动
- 在[[图解法]]中，通过平移等值线至与[[可行域]]边界相切，即可找到[[最优解]]

## 与相关概念的关系

| 概念 | 关系 |
|------|------|
| [[约束条件]] | 目标函数必须在约束条件定义的可行域内求解 |
| [[决策变量]] | 目标函数由决策变量组成 |
| [[可行域]] | 目标函数在可行域内寻找最优值 |
| [[最优解]] | 使目标函数达到最优值的可行解 |
| [[单纯形法]] | 用于求解多变量目标函数最优解的算法 |

## 总结

目标函数是[[线性规划]]的三大基本要素之一（目标函数、约束条件、决策变量），它将决策问题中的真实目标（如利润最大化、成本最小化）转化为数学表达式，为定量决策提供了清晰的优化方向和评价标准。
