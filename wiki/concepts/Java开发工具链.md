# Java开发工具链：JDK、JRE、JVM层级体系

## 概述

JDK、JRE、JVM是Java技术栈中三个核心组件，构成从开发到运行的完整层级体系。理解它们之间的关系是掌握[[Java开发环境]]的基础。

## 层级结构

```
┌─────────────────────────┐
│         JDK             │  ← Java开发工具包（包含编译、运行工具）
│  ┌───────────────────┐  │
│  │       JRE         │  │  ← Java运行环境（面向用户）
│  │  ┌─────────────┐  │  │
│  │  │    JVM      │  │  │  ← Java虚拟机（核心解释执行器）
│  │  └─────────────┘  │  │
│  └───────────────────┘  │
└─────────────────────────┘
```

## 核心组件详解

### 1. JDK（Java Development Kit）

JDK是Java的**开发工具包**，是整个Java技术的核心：

- **包含内容**：编译工具（javac）、运行资源、各种开发工具
- **主要功能**：使Java开发者能够编译和运行自己的Java程序
- **javac指令**：将.java源文件编译成.class字节码文件
- **包含关系**：JDK包含了JRE

> JDK是面向**开发者**的工具包，普通用户运行程序不需要JDK。

### 2. JRE（Java Runtime Environment）

JRE是Java的**运行环境**，并非开发环境：

- **不包含**：编译器、调试器等开发工具
- **面向对象**：仅针对需要运行Java程序的**最终用户**
- **主要功能**：提供运行Java程序所需的环境
- **包含关系**：JRE包含了JVM

> Java开发者需要JDK来编译代码，但运行时代码只需要JRE。

### 3. JVM（Java Virtual Machine）

JVM是**Java虚拟机**，是一种虚构出来的计算机规范：

- **工作原理**：通过在实际计算机上仿真模拟各种计算功能
- **核心职责**：解释执行.class字节码文件
- **跨平台特性**：所有平台上的JVM向编译器提供相同的接口，实现"一次编译，多处运行"

## 工作流程

```
源代码        编译        字节码       解释执行
.java  ──javac──>  .class  ──JVM──>  程序运行
```

1. 开发者编写.java源代码
2. javac编译器将.java文件编译成.class字节码文件
3. JVM读取并解释执行.class字节码文件

## 层级关系总结

| 组件 | 全称 | 类型 | 包含 | 面向对象 |
|------|------|------|------|----------|
| JDK | Java Development Kit | 开发工具包 | JRE | 开发者 |
| JRE | Java Runtime Environment | 运行环境 | JVM | 用户 |
| JVM | Java Virtual Machine | 虚拟机 | - | 平台 |

## 关键意义

JVM是Java实现[[跨平台特性]]的核心。通过JVM这一中间层，Java程序只需编译一次，即可在任何安装了JVM的平台上运行，这是Java语言最重要的设计优势之一。
