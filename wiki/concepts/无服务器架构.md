# 无服务器架构

## 定义

无服务器架构（Serverless Architecture）是开发软件应用程序的一种模型。在此架构中，底层基础设施的预配和管理由云服务提供商负责，用户无需关心服务器的运维工作。

## 核心特征

### 按需付费模式
用户只需为正在使用的基础设施付费，无须为空闲CPU时间或未使用的空间付费。这种模式显著降低了成本，因为资源仅在应用程序执行时被使用。

### 基础设施托管
云服务提供商负责处理底层基础设施的预配、管理和维护工作，开发人员可以专注于业务逻辑的实现。

### 自动扩展
扩展任务由云提供商自动处理，无需人工干预即可应对流量波动。

### 后端简化
无服务器架构简化了后端代码，减少了开发工作量，降低了开发和运维成本。

## 主要优势

- **成本优化**：按需付费，无闲置资源浪费
- **加速交付**：减少运维负担，加快上市时间
- **弹性扩展**：自动应对流量变化
- **专注业务**：开发团队聚焦业务逻辑而非基础设施

## 典型用例

- 多媒体处理
- 实时流媒体
- 聊天机器人
- CI/CD管道
- 物联网传感器消息处理

## 技术实现

在微服务架构中，可使用以下服务实现无服务器计算：

- AWS Lambda
- API Gateway
- API Step Functions

## 与其他架构的关系

无服务器架构通常与[[concepts/微服务架构]]结合使用，可以作为微服务的补充或替代方案。与传统的[[concepts/整体式架构]]相比，无服务器架构更适合事件驱动型和轻量级的应用场景。
