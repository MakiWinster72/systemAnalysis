# 网络核心层设计

## 概念定义

网络核心层（Core Layer）是[[分层设计]]模型中的最高层次，作为整个网络的高速骨干，负责在不同子网之间高速转发数据。核心层的设计直接影响网络的整体性能和稳定性。

## 核心层在三层架构中的位置

典型的企业网络采用三层架构：

```
    ┌─────────────┐
    │   核心层    │  ← 高速骨干
    │  Core Layer │
    └──────┬──────┘
           │
    ┌──────┴──────┐
    │   汇聚层    │  ← 策略控制
    │Aggregation  │
    └──────┬──────┘
           │
    ┌──────┴──────┐
    │   接入层    │  ← 用户接入
    │ Access Layer│
    └─────────────┘
```

## 核心层设计原则

根据[[summaries/4.4.2网络设讣]]中的描述，核心层交换机的选型策略应具备以下特点：

1. **高性能与高速率**：核心层需处理全网所有流量，必须具备强大的数据转发能力
2. **便于升级和扩展**：预留扩展空间，适应未来业务增长
3. **高可靠性**：采用冗余设计，确保网络不间断运行
4. **强大的网络控制能力**：支持流量整形、QoS等高级功能
5. **良好的可管理性**：便于网络监控和故障排查

## 与其他层次的关系

- **与[[汇聚层]]的关系**：汇聚层是核心层和[[接入层]]的分界面，汇聚层交换机需处理来自接入层设备的所有通信量，并提供到核心层的上行链路
- **与[[网络安全设计]]的关联**：核心层作为网络骨干，是安全策略部署的重要位置

## 设计要点

| 要点 | 说明 |
|------|------|
| 带宽规划 | 根据全网流量需求，合理规划核心链路带宽 |
| 冗余设计 | 采用双核心或环形拓扑，避免单点故障 |
| 设备选型 | 选用高端口密度、高背板带宽的模块化交换机 |
| 协议选择 | 采用快速收敛的路由协议，确保故障快速恢复 |

## 核心层与通信子网设计

核心层设计是[[summaries/4.4.2网络设讣]]中"通信子网设计"的重要组成部分。拓扑结构设计需综合考虑费用、灵活性和可靠性三个方面。

## 总结

核心层是网络架构的"高速公路"，其设计质量决定了整个网络的性能上限。设计时应坚持高性能、高可靠、高可用的原则，同时预留扩展能力，并结合[[网络安全设计]]确保骨干层面的安全防护。
