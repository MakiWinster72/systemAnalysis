# 自底向上的数据仓库设计方法

## 定义

自底向上的数据仓库设计方法是一种渐进式的开发策略，其核心思想是从企业中最关键的部门或功能需求开始，先以最少的投资完成当前需求，获得最快的回报，然后再不断扩充、不断完善。

## 设计流程

采用该方法进行数据仓库设计时，遵循以下演进路径：

1. **识别关键需求**：从企业中最关键的部门或功能需求入手
2. **最小投入启动**：以最少投资完成当前需求
3. **快速获得回报**：尽快产生业务价值
4. **逐步扩充完善**：在成功基础上不断扩展
5. **整合形成企业级仓库**：从多个独立数据集市抽取数据，最终形成企业级数据仓库

## 主要特点

| 特点 | 说明 |
|------|------|
| 渐进式开发 | 分阶段实施，降低风险 |
| 投资少 | 初期投入小，适合预算有限的情况 |
| 见效快 | 能快速获得回报，产生业务价值 |
| 人员投入少 | 开发过程中人员需求较低 |
| 风险可控 | 单个项目失败影响范围相对有限 |

## 优点

- 企业能够以较小的投入获得较高的数据仓库应用收益
- 开发过程中人员投入较少
- 容易获得成效，增强团队信心
- 能够灵活适应业务变化

## 潜在风险

如果某个项目的开发失败，可能造成企业整个数据仓库系统开发的延迟。

## 适用场景

该方法一般用于：

- 企业希望对数据仓库技术进行评价，以确定该技术的应用方式、地点和时间
- 希望了解实现和运行数据仓库所需要的各种费用
- 数据仓库的应用目标并不是很明确时
