# 业务流程（Business Process）

## 定义

根据 **ISO 9000** 的定义，**业务流程（Business Process）** 是一组将输入转化为输出的相互关联或相互作用的活动。它是对现实世界真实业务过程的形式化建模，是信息系统设计的基础概念。

## 流程的基本特点

业务流程具有以下六大特点：

| 特点 | 说明 |
|------|------|
| **目标性** | 流程有明确的业务目标 |
| **内在性** | 流程蕴含着业务活动的内在逻辑 |
| **整体性** | 流程是由多个活动组成的有机整体 |
| **动态性** | 流程随时间和条件动态变化 |
| **层次性** | 流程可以逐层分解为子流程 |
| **结构性** | 流程具有明确的结构和顺序 |

## 流程六要素

业务流程包含6个基本要素：

1. **输入资源**：流程的起始条件，如用户提交的申请数据
2. **活动**：具体的业务处理逻辑，如数据验证、计算等
3. **活动的相互作用**：活动之间的相互关系和顺序
4. **输出结果**：流程执行后的产出，如通知、文档等
5. **用户**：流程的服务对象
6. **价值**：流程为用户创造的价值

以在线教育平台的"开通课程"流程为例：
- 输入资源：注册用户名
- 活动：合法性判断、时间判断、费用计算等业务逻辑
- 输出结果：短信和邮件通知
- 用户：已缴费的注册用户
- 价值：用户可学习课程

## 流程分类

### 流程定义 vs 流程实例

- **流程定义**：对业务过程的形式化表示，定义了过程运行中的活动、开始和完成条件、活动间的切换规则等
- **流程实例**：也称为工作，是流程定义的运行实例，即一次具体的流程操作（如一次在线测试、一次在线支付）

## 应用价值

通过对业务流程的设计和建模，可以：

- 使用信息系统取代传统的手工处理
- 提高业务处理的效率和准确性
- 降低业务处理成本
- 完善系统分析和设计过程中的遗漏和不合理之处

## 流程与工作流的区别

| 对比项 | 业务流程 | 工作流 |
|--------|----------|--------|
| 定义层次 | 更抽象的概念 | 更具体的技术实现 |
| 侧重点 | 业务逻辑和价值 | 自动执行和过程控制 |
| 实现方式 | 可以是手工或自动化 | 通常部分或完全自动化执行 |
