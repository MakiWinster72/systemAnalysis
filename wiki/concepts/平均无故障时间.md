# 平均无故障时间（MTTF）

## 定义

**平均无故障时间**（Mean Time To Failure，MTTF）是指产品在规定的条件下和规定的时间内，完成规定功能的能力的期望值。它从时间t=0开始计算，到系统发生故障时为止的系统持续运行时间。

## 计算公式

### 基本定义

MTTF定义为可靠度函数R(t)的积分：

$$MTTF = \int_0^{\infty} R(t)dt$$

当可靠度函数为指数分布时：

$$R(t) = e^{-\lambda t}$$

则：

$$MTTF = \frac{1}{\lambda}$$

其中，λ为**失效率**，指系统在单位时间内发生失效的预期次数（假设为常数）。

### 时间模型中的MTTF

在时间模型（参见[[系统可靠性模型]]）下，基于故障数随调试减少的假设，系统的平均无故障时间可表示为：

$$MTTF = \frac{1}{c\left(\frac{E_0}{I} - E_c(t)\right)}$$

或等效形式：

$$MTTF = \frac{C E_0}{C\left(E_0/I - E_c(t)\right)^2}$$

其中：
- E₀/I 为单位指令的初始故障密度
- Eₐ(t) 为调试时间t内纠正的故障数
- C 为风险函数的比例常数

## MTTF与系统结构的关系

### 串联系统

在[[串联系统]]中，系统的总失效率为各子系统失效率之和：

$$\lambda = \lambda_1 + \lambda_2 + ... + \lambda_n$$

因此，串联系统的MTTF为：

$$MTTF_{series} = \frac{1}{\lambda_1 + \lambda_2 + ... + \lambda_n}$$

这意味着子系统越多，系统的整体MTTF越低，可靠性越差。

### 并联系统

在[[并联系统]]中，增加冗余子系统数量可以提高系统的平均无故障时间。并联系统中有 n-1 个**冗余子系统**，随着冗余子系统数量的增加，系统的MTTF也随之增加。这体现了[[冗余技术]]在提高系统可靠性方面的重要作用。

### 模冗余系统

在[[模冗余系统]]中，由 m (m = 2n+1) 个相同子系统和表决器组成。这种结构通过多数表决机制提供容错能力，其MTTF取决于单个子系统的可靠度和冗余程度。

## 示例计算

根据文档中的例子：

假设同一型号的1000台计算机，在规定的条件下工作1000小时，其中有10台出现故障：

- 每台计算机千小时的可靠度：R(1) = (1000-10)/1000 = 0.99
- 失效率：λ = 10/(1000×1000) = 1×10⁻⁵
- **MTTF = 1/(1×10⁻⁵) = 10⁵ h**

## 与系统可用性的关系

[[系统可用性]]是综合反映MTTF和[[平均故障修复时间]]（MTTR）的指标：

$$系统可用性 = \frac{MTTF}{MTTR + MTTF} \times 100\%$$

由于MTTR通常远小于MTTF，实际应用中常近似认为[[平均故障间隔时间]]（MTBF）≈MTTF，即：

$$MTBF = MTTR + MTTF \approx MTTF$$

## 相关概念

- [[可靠度]]R(t)：产品在规定条件下完成规定功能的概率度量
- [[失效率]]λ：系统单位时间内发生失效的预期次数
- [[平均故障修复时间]]（MTTR）：系统发生故障后平均需要的修复时间
- [[平均故障间隔时间]]（MTBF）：MTTF与MTTR之和
- [[系统可用性]]：综合反映MTTF和MTTR的综合指标
- [[系统可靠性模型]]：包括时间模型、故障植入模型和数据模型
- [[串联系统]]：所有子系统都正常工作系统才能工作的系统结构
- [[并联系统]]：任一子系统正常工作系统就能工作的系统结构
- [[冗余技术]]：通过增加冗余部件提高系统可靠性的方法
