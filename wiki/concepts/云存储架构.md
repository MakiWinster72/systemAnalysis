# 云存储架构

## 概念定义

云存储（Cloud Storage）是一种新兴的数据存储方案，通过[[集群应用]]、网格技术和[[分布式文件系统]]等功能，将网络中大量不同类型的存储设备通过应用软件集合起来协同工作，共同对外提供数据存储和业务访问功能。

## 核心特征

- **高可用性**：保证数据的安全性和持续可访问
- **高可扩展性**：根据需求灵活扩展存储容量
- **经济高效**：节约本地存储空间和维护成本
- **随时随地访问**：通过任何可连网装置在任意时间、任意地点存取数据

## 主流云存储服务

### Amazon S3

Amazon Simple Storage Service (S3) 是AWS环境中广泛使用的云存储解决方案：

- **存储单元**：在AWS中称为"存储桶"（Bucket），用于存储对象
- **功能特性**：存储类型选择、版本控制、生命周期策略、存储桶策略
- **数据管理**：AWS负责对象的生命周期管理，包括IAM策略和数据保护
- **优势**：灵活性高、经济高效、持久安全、高可用性

### Azure Cloud Storage

Microsoft Azure提供的云存储服务：

- **可用性**：99.95%正常运行时间
- **价格**：约0.18美元/GB/月
- **特点**：高安全性，配备全面的管理访问和开发人员工具堆栈

### 谷歌云存储

Google提供的云存储产品：

- **价格**：约0.02美元/GB/月
- **特点**：多地区可用，高耐用性，易于与其他Google服务集成

## 技术架构

云存储系统通常包含以下层次：

```
┌─────────────────────────────────┐
│         应用层                  │
│   (云存储访问接口/API)           │
├─────────────────────────────────┤
│         业务管理层               │
│  (用户管理、计费、监控)           │
├─────────────────────────────────┤
│         存储层                   │
│   (分布式存储节点集群)            │
└─────────────────────────────────┘
```

## 与其他技术的关系

云存储与[[负载均衡策略]]、CDN内容分发等[[summaries/16.4.2 Web应用系统数据存储]]中的技术密切相关。云存储通常配合[[分布式缓存]]和CDN使用，以提供更好的读写性能和用户体验。
