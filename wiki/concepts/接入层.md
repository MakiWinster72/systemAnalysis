# 网络接入层设计

## 定义

网络接入层（Access Layer）是OSI七层模型或TCP/IP五层模型中最接近终端用户的层次，直接负责将最终用户设备连接到网络。在[[summaries/4.4.2网络设讣|网络设计]]的分层架构中，接入层是整个网络拓扑的第一层级。

## 核心功能

接入层的主要目的是**允许终端用户连接到网络**，完成以下关键任务：

- 用户终端设备（PC、移动设备、打印机等）的物理接入
- 基本的网络访问控制
- 本地流量的交换与转发
- 提供网络接入点

## 设计原则

根据[[summaries/4.4.2网络设讣]]中关于[[分层设计]]的要求，接入层交换机具有两个显著特点：

### 1. 低成本

接入层设备数量众多，需要控制整体采购和运维成本。采用性价比高的设备是基本原则。

### 2. 高端口密度

为尽可能多地接入终端用户，接入层交换机应具备丰富的端口数量，最大化利用机房空间和布线资源。

## 与其他层次的关系

```
┌─────────────┐
│   核心层    │  ← 高速骨干传输
│ (Core Layer) │
└──────┬──────┘
       │
┌──────▼──────┐
│   汇聚层    │  ← 策略控制、数据处理
│(Distribution)│
└──────┬──────┘
       │
┌──────▼──────┐
│   接入层    │  ← 用户终端接入
│(Access Layer)│
└─────────────┘
```

接入层位于[[汇聚层]]和终端用户之间，是[[分层设计]]模型中最基础的层次。接入层设备通过上联端口连接到汇聚层交换机，实现与核心层和外部网络的通信。

## 设备选型要点

在[[summaries/4.4.2网络设讣]]的设备选型部分，针对汇聚层/接入层交换机提出了以下选型策略：

| 要求 | 说明 |
|------|------|
| 灵活性 | 支持多种接入方式和协议 |
| 高性能 | 满足端口线速转发 |
| 经济性 | 在满足要求的基础上尽量降低成本 |
| 易用性 | 配置简单，便于管理 |
| QoS能力 | 具备一定的服务质量控制能力 |
| 可管理性 | 支持多级网络管理 |

## 设计注意事项

1. **端口规划**：根据用户数量和分布合理配置接入交换机数量和端口密度
2. **上联带宽**：确保上联链路带宽满足汇聚层通信需求
3. **冗余设计**：关键位置可考虑双上联提高可靠性
4. **VLAN划分**：合理规划[[网络安全设计|网络安全]]策略，控制广播域

## 总结

网络接入层设计是[[网络设计]]的重要组成部分，其核心目标是实现终端用户的高效、经济接入。设计时需平衡成本与性能，确保与汇聚层、核心层的协调配合，共同构建稳定可靠的企业网络。
