## 分布函数

### 定义

设随机变量为ξ，则其**分布函数**定义为：

```
F(x) = P(ξ ≤ x), -∞ < x < +∞
```

分布函数描述了随机变量ξ的取值不超过实数x的概率，是随机变量统计规律的完整描述。

### 基本性质

分布函数F(x)具有以下核心性质：

| 性质 | 描述 |
|------|------|
| 有界性 | 0 ≤ F(x) ≤ 1，-∞ < x < +∞ |
| 极限性 | lim F(x) = 0 (x→-∞), lim F(x) = 1 (x→+∞) |
| 单调性 | 若x₁ < x₂，则F(x₁) ≤ F(x₂)（非递减） |
| 右连续性 | F(x+0) = F(x) |

### 重要公式

- **区间概率**：P(a < ξ ≤ b) = F(b) - F(a)
- **单点概率**：P(ξ = a) = F(a) - F(a-0)

### 分类

分布函数根据对应的随机变量类型分为：

- **离散型分布函数**：对应[[离散型随机变量]]，分布函数为阶梯函数
- **连续型分布函数**：对应[[连续型随机变量]]，可表示为分布密度函数的积分

### 与其他概念的关系

- 分布函数是[[随机变量]]的统计规律描述
- 对于连续型随机变量，F(x)的导数即为[[分布密度函数]]p(x)
- 分布函数是计算[[数学期望]]的基础

> 本概念源自：[[summaries/2.1.2随机变量及其分布]]

### 备注

分布函数能够完整地描述随机变量的统计规律，是连接概率论理论与实际应用的重要桥梁。在系统分析师的实际工作中，分布函数常用于分析系统故障概率、性能指标分布等场景。
