# 多处理机系统：定义、分类与特点

## 定义

多处理机（Multi-Processor）是指具有**两个或两个以上处理机**的计算机系统，其核心特征包括：

- 共享I/O子系统
- 在操作系统统一控制下运行
- 通过共享主存或高速通信网络进行通信
- 协同求解复杂问题

多处理机系统中的各处理部件、存储模块和各种外设通过**互连网络**相互通信，互连网络已成为并行处理系统的核心组成部分，对整个计算机系统的性能/价格比起着决定性影响。

## 设计目标

多处理机系统追求两大核心目标：

1. **性能提升**：利用多台处理机进行多任务处理来提高运算速度
2. **可靠性增强**：利用系统的重组能力提高可靠性、适应性和可用性

## 与并行处理机的核心区别

多处理机与[[summaries/3.5.1多处埋机系统概述|并行处理机]]的根本差异在于**并行性层次不同**。

| 特性 | 并行处理机（SIMD） | 多处理机（MIMD） |
|------|-------------------|-----------------|
| **结构** | 针对数组/向量处理设计 | 通用性强，结构灵活 |
| **并行粒度** | 操作一级并行 | 任务级并行 |
| **派生方式** | 指令直接启动多部件 | 需专门指令控制派生 |
| **同步机制** | 自然同步（同控制器） | 独立进度（各机异步） |
| **资源调度** | 屏蔽控制（固定单元） | 动态分配与调度 |

并行处理机基于[[SIMD]]结构，只有一个控制器但有多个处理单元，所有处理单元执行相同指令但处理不同数据，因此也被称为**矩阵处理机**或**阵列处理机**，特别适合矩阵计算。

多处理机采用[[MIMD]]架构，每个处理机可独立执行不同指令，实现真正的[[并行任务派生]]能力。

## 系统分类

根据**内存访问方式**和**耦合程度**，多处理机系统可分为以下类型：

### 紧耦合系统（紧密耦合）

采用**共享存储方式**，多个处理机通过互连网络共享公共的共享存储器（Shared Memory, SM）。

**系统特点：**
- 每个处理机可自带局部存储器，也可自带Cache
- 存储器模块可采用流水线工作方式
- 容易管理和利用资源
- 程序员没有划分数据的负担，编程比较容易
- 能加快大程序的运行速度
- 适用于多用户的一般应用和分时应用

**局限性：**
- 处理机数目有限
- 扩充比较困难

**分类：**
- 按处理机类型：同构或异构
- 按对称性：对称或非对称
- 常见组合：同构对称式和异构非对称式

### 松耦合系统（间接耦合）

采用**分布式存储方式**，每个处理机独占本地存储器（Local Memory, LM），各处理机通过互连网络相连，结构更像计算机网络。

**系统特点：**
- 每个处理机带有一个本地存储器和一组I/O设备
- 结构灵活、容易扩充
- 较适合粗粒度的并行计算

**局限性：**
- 难以在各处理机之间实现复杂数据结构的数据传送
- 任务动态分配复杂
- 现有软件可继承性差
- 需要设计新的并行算法
- 编程困难，增加了通信开销

**典型代表：** [[MPP]]（Massively Parallel Processing，海量并行处理）

## 对称多处理机（SMP）

SMP（Symmetric Multiprocessing）也称为**共享存储多处理机**，它与MPP最大的差别在于存储系统架构。SMP具有统一共享的SM，而MPP则是每个处理机都拥有自己的LM。

### 共享存储模型

共享存储方式有三种模型，其区别在于存储器和外设如何共享或分布：

#### 1. UMA（均匀存储器存取）模型

- **物理存储器被所有处理机均匀共享**
- 所有处理机对存储器的访问时间和带宽是均匀的
- 处理机访问本地存储器和远程存储器的时间相同
- 适用于对存储器访问延迟不敏感的通用计算场景

#### 2. NUMA（非均匀存储器存取）模型

- **访问时间随存储字的位置不同而变化**
- SM物理上分布在所有处理机的LM上
- 所有LM的集合组成全局地址空间，可被所有处理机访问
- 处理机访问本地LM较快，但访问远程存储器较慢（通过互连网络产生附加时延）
- 兼顾了共享存储的编程便利性和分布式存储的可扩展性

#### 3. COMA（只用高速缓存的存储器结构）模型

- COMA是NUMA机的一种**特例**
- 将NUMA中的分布主存储器换成了高速缓存
- 每个处理机结点上没有传统存储器层次结构
- 全部高速缓冲存储器组成全局地址空间
- 远程高速缓存访问需要借助于分布高速缓存目录进行
- 提供更均匀的访问延迟分布

### SMP与MPP的核心对比

| 特性 | SMP（对称多处理机） | MPP（海量并行处理） |
|------|-------------------|-------------------|
| **存储架构** | 统一共享存储（SM） | 分布式本地存储（LM） |
| **存储模型** | UMA/NUMA/COMA | 仅本地存储 |
| **内存访问** | 统一地址空间 | 需消息传递 |
| **扩展性** | 有限 | 高度可扩展 |
| **编程难度** | 较低 | 较高 |
| **一致性** | 需Cache一致性协议 | 无Cache一致性问题 |

## 互连网络

互连网络是用来连接一个计算机系统中的各处理部件、存储模块以及各种外设，在系统软件控制下，使各功能部件相互通信的硬件网络结构。互连网络是多处理机系统的核心基础设施，对整个系统的性能/价格比起着决定性影响。

### 互连函数

为了反映不同互连网络的连接特性，每种互连网络可用一组函数来描述。如果将互连网络的 n 个输入端和输出端分别用整数 0, 1, …, n-1 表示，则[[互连函数]]表示相互连接的输出端和输入端之间的一一对应关系。基本的互连函数主要有以下几种：

| 互连函数 | 功能描述 |
|---------|---------|
| **恒等置换** | 相同编号的输入端与输出端一一对应互连 |
| **交换置换** | 实现二进制地址编号中第 0 位位值不同的输入端和输出端之间的连接 |
| **方体置换** | 实现二进制地址编号中第 k 位位值不同的输入端和输出端之间的连接 |
| **均匀洗牌置换** | 将输入端二进制地址循环左移一位 |
| **蝶式置换** | 将二进制地址的最高位和最低位互换位置 |
| **位序颠倒置换** | 将二进制地址的位序颠倒过来 |

### 互连方式

在多处理机系统中，衡量互连网络性能好坏的主要因素是**连接度、延时性、带宽、可靠性和成本**。其中连接度是指一个结点与其他结点的连接程度，直接连接的结点数越多，连接性越好；延时性是指从一个结点传送信息到任何另一个结点所需的时间，通常用结点间最大距离表示。

主要的互连方式包括：

| 方式 | 特点 |
|------|------|
| **[[总线方式]]** | 最简单的方法，通过共享总线连接各处理机，配备全局存储器，争用最严重 |
| **[[交叉开关]]** | 把争用现象降到最低，但连接复杂度最高 |
| **开关枢纽** | 由仲裁单元和开关单元组成，分别完成冲突处理和连接 |
| **多端口存储器** | 将交叉点仲裁逻辑移到存储器控制，每个存储器模块有多个存取端口 |
| **[[多级互连网络]]** | MIMD和SIMD计算机都使用，是总线方式和交叉开关的折中，采用模块结构扩展性好，但时延随网络级数上升 |

设计互连网络时，应综合考虑通信工作方式、控制策略、交换方式和网络拓扑等因素。

## 虚拟共享存储器技术（SVM/DSM）

为了解决分布式存储方式编程困难和通信开销大的问题，引入了**虚拟共享存储器**（Shared Virtual Memory, SVM）或**共享分布存储器**（Distributed Shared Memory, DSM）技术。

### 基本原理

将物理上分散的各个处理机所拥有的本地存储器，在逻辑上加以统一编址，形成一个统一的虚拟地址空间来实现存储器的共享。每个处理机可以访问全局存储器的任一位置，用户可以像访问本地存储器一样方便地访问全局任意位置。

### 实现途径

SVM系统可以兼具紧耦合系统和松耦合系统的优点，主要有三种实现途径：

#### 1. 硬件实现
- 将传统[[Cache]]技术扩展应用到松耦合系统中
- 需要在现有松耦合系统上增加专用部件
- 可取得高效的实现
- 但增加了硬件复杂度

#### 2. 操作系统和库实现
- 通过虚拟存储管理机制取得共享和一致性
- 在现有松耦合系统上不增加任何专用部件
- 实现简单，成本较低
- 现有SVM系统大多采用此途径

#### 3. 编译实现
- 自动将共享访问转换成同步和一致原语
- 要求用户显式控制全局数据
- 当传送大量数据或进行迁移时极其复杂
- 自动化程度高但灵活性差

### 技术优势

SVM技术的核心优势在于：
- **软件移植方便**：用户以前在紧耦合系统上编写的程序可以不加修改地在SVM系统上运行
- **解决数据传递问题**：解决了难以对复杂数据结构进行传递的问题
- **支持进程迁移**：解决了难以进行[[进程迁移]]（Process Migration）的问题

## 关键技术问题

1. **[[并行任务派生]]**：一个任务执行时可派生出与之并行执行的其他任务
2. **[[进程同步]]**：协调不同处理机上进程的执行顺序
3. **资源分配与进程调度**：动态管理处理机数目和共享资源，直接影响系统效率
4. **[[存储一致性]]**：在共享存储系统中维护数据一致性
5. **[[Cache一致性]]**：多处理机共享存储系统中的Cache一致性问题
6. **通信优化**：减少消息传递延迟和通信开销
7. **[[互连网络]]设计**：选择合适的互连函数和互连方式以优化系统性能

## 系统类型对比总览

| 特性 | 紧耦合系统 | 松耦合系统(MPP) |
|------|-----------|----------------|
| **存储方式** | 共享存储 | 分布式存储 |
| **扩展性** | 扩充困难 | 容易扩展 |
| **编程难度** | 比较容易 | 困难 |
| **并行粒度** | 细粒度 | 粗粒度 |
| **通信开销** | 低 | 较高 |
| **典型系统** | SMP | MPP |
| **存储模型** | UMA/NUMA/COMA | 仅本地存储 |
| **互连方式** | 总线/交叉开关/多级网络 | 多级互连网络 |

## 相关概念

- [[MIMD]]：多指令流多数据流，多处理机的核心技术架构
- [[SIMD]]：单指令流多数据流，并行处理机的技术架构
- [[SMP]]：对称多处理机，紧耦合共享存储系统的典型代表
- [[MPP]]：海量并行处理，松耦合分布式存储系统的典型代表
- [[NUMA]]：非均匀存储器存取模型
- [[SVM/DSM]]：虚拟共享存储器技术
- [[互连函数]]：描述互连网络连接特性的数学函数
- [[总线方式]]：最简单的互连方式
- [[交叉开关]]：连接复杂度最高但争用最低的互连方式
- [[多级互连网络]]：总线和交叉开关的折中方案
- [[并行计算]]：利用多处理机进行协同计算的广泛领域
- [[Cache一致性]]：共享存储系统中的重要技术问题
