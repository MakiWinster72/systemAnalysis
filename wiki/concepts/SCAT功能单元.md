# SCAT功能单元：传感器-控制器-执行器-传输设备模型

## 概述

SCAT是[[summaries/21.4.4服务平台相关技术]]中提到的CPS（信息物理系统）控制过程物理设备模型，代表了自动控制系统中四种核心功能单元：传感器(Sensor)、控制器(Controller)、执行器(Actuator)和传输设备(Transmitter)。

## 组件详解

### 传感器（Sensor）

传感器是SCAT模型的感知层，负责物理量测量。它将被控对象的物理量（如温度、压力、位置、速度等）转换为可处理的信号，是控制系统的"眼睛"，为控制器提供实时状态信息。

### 控制器（Controller）

控制器是SCAT模型的大脑，负责：
- 接收传感器传来的测量数据
- 将测量结果与预期值进行比较
- 计算测量误差和预期误差
- 生成控制指令

控制器是整个SCAT模型的核心，决策功能在此完成。

### 执行器（Actuator）

执行器是SCAT模型的执行层，负责接收控制器的指令并作用于被控对象。执行器将控制信号转换为物理动作，如阀门开闭、马达转动、加热器启停等，是控制系统的"手脚"。

### 传输设备（Transmitter）

传输设备负责在SCAT各组件之间传输数据和指令。传输设备确保传感器数据及时送达控制器，同时将控制指令可靠传递至执行器，是控制系统的"神经系统"。

## SCAT在CPS中的应用

在CPS系统中，[[concepts/信息物理系统]]的自动控制通过SCAT功能单元实现：

```
传感器 → 传输设备 → 控制器 → 传输设备 → 执行器
   ↑                                      ↓
   └──────────── 反馈回路 ←───────────────┘
```

### 支持的控制模式

SCAT功能单元支撑多种[[concepts/自动控制系统]]行为模式：

1. **开环控制**：控制器发出指令给执行器，无反馈环节
2. **闭环控制**：传感器实时采集输出，控制器根据反馈调整控制策略
3. **顺序控制**：SCAT协同完成有序的控制步骤
4. **批量控制**：SCAT按预定流程处理有限数量的物料

## 通信要求

SCAT各组件之间的通信需要满足：

- **周期性**：数据传输间隔重复，如每30ms一次
- **确定性**：消息时延稳定在给定阈值内
- **可靠性**：告警和紧急事件需要及时确认和响应
