# CPS分层架构

## 概述

CPS（信息物理系统）分层架构是将CPS系统按规模划分为三个层级的体系结构设计。这三个层级之间呈递进与扩展关系，从最小单元逐步扩展到企业级系统。

## 三层架构体系

### 1. 单元级CPS

单元级是CPS系统中具有**不可分割性**的最小单元，可以是一个部件或一个产品。

**核心构成：**
- 硬件：具备传感、控制功能的机械装置（如机械臂、传动轴承等）
- 软件：嵌入式软件等

**核心功能：** "感知-分析-决策-执行"数据闭环系统
- 可感知
- 可计算
- 可交互
- 可延展
- 自决策

**典型应用：** 智能轴承、智能机器人、智能数控机床

### 2. 系统级CPS

系统级是由多个单元级CPS和跨越不同单元级CPS的网络共同构成的有机组合体。

**关键特征：**
- 多个单元级CPS通过工业网络（工业现场总线、工业以太网等）连接
- 实现更大范围、更宽领域的数据自动流动

**核心能力：**
- 互联互通：多个单元级CPS之间的连接
- 互操作：异构系统之间的协同工作

**应用场景：**
- 智能生产线
- 智能车间
- 智能工厂

### 3. 系统之系统级（SoS）

系统之系统级是由系统级CPS通过工业云、工业大数据等智能服务平台构建而成。

**技术支撑：**
- 工业云平台
- 工业大数据平台

**服务目标：** 提供企业级层面的数字化运营服务

## 层级关系图

```
┌─────────────────────────────────────┐
│         系统之系统级（SoS）           │
│    工业云、大数据等智能服务平台        │
├─────────────────────────────────────┤
│            系统级CPS                 │
│    CPS总线等网络 + 多个单元级         │
├─────────────────────────────────────┤
│           单元级CPS                  │
│  物理实体、控制装置、传感器等          │
└─────────────────────────────────────┘
```

## 与物联网的关系

CPS强调**循环反馈**机制：
1. 感知物理世界
2. 通过通信与计算处理信息
3. 对物理世界起反馈控制作用

物联网可视为CPS的一种简约应用，CPS让物联网的定义和概念更加明晰。
