# 代码行（LOC）软件规模度量

代码行（Line of Code，LOC）是软件项目规模度量的经典指标，指所有可执行的源代码行数。

## 定义与组成

LOC包括以下内容：
- 可交付的工作控制语言语句
- 数据定义
- 数据类型声明
- 等价声明
- 输入输出格式声明等

## 应用场景

### 工作量与成本估算

项目经理可以通过历史项目审计核算本企业的单行代码价值。例如：
- 某公司每万行Java源代码约250KB
- 视频点播系统源文件3.75MB → 约15万行代码
- 累计投入240人·月，费用10000元/人·月
- 单行代码价值 = (240×10000)/150000 = 16元/LOC
- 人·月平均代码行数 = 150000/240 = 625LOC/人·月

### 复用代码等价估算

对于可复用代码，等价新代码行计算公式：

```
等价LOC = [(重新设计% + 重新编码% + 重新测试%) / 3] × 已有LOC
```

例如：10000LOC中30%需重新设计、50%需重新编码、70%需重新测试，则等价LOC = [(30%+50%+70%)/3] × 10000 = 5000LOC

## 局限性

LOC作为规模度量指标存在一定局限性：
- 软件本身的复杂性导致估算偏差
- 历史经验和估算工具的缺乏
- 人为错误的影响

因此，估算错误是软件项目失败的主要原因之一，实际应用中需结合多种方法进行综合估算。
