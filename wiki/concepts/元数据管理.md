# 元数据管理体系

## 概念定义

元数据管理体系是[[数据治理]]的重要组成部分，也是国家电子商务标准体系中**业务标准**的核心组成部分。元数据（Metadata）是描述数据的数据，它为系统的各类数据提供了上下文环境，使系统能够更好地了解、管理和使用数据。

在[[电子商务标准体系]]中，业务标准包含元数据、单证格式、流程与接口、注册维护等内容，元数据管理体系为电子商务业务提供数据描述的统一规范，确保数据在不同系统和业务流程之间的一致性和可理解性。

## 元数据分类

元数据一般分为两类：

### 技术元数据

技术元数据是存储关于数据仓库系统技术细节的数据，是用于开发和管理数据仓库使用的数据。

**核心作用**：
- 明确数据的存储和结构
- 厘清数据关系
- 提升开发效率
- 了解数据来源和去向
- 支持[[数据血缘关系]]追溯和影响分析

### 业务元数据

业务元数据描述数据的业务含义、业务规则等，可以为数据应用提供更好的服务。

## 七种管理方式

元数据管理主要分为以下七种方式，涵盖数据全生命周期：

| 管理类型 | 说明 |
|---------|------|
| **数据源元数据** | 数据库模型设计文档、业务系统数据字典、数据接口文件等 |
| **ETL规则元数据** | 涉及数据源元数据、目标系统元数据、ETL流程、源与目标映射关系 |
| **数据仓库元数据** | 事实表、维度、属性、层次等信息，物理表与多维模型映射关系 |
| **报表元数据** | 报表和指标（度量）的描述信息 |
| **接口文件格式元数据** | 接口数据文件命名、传输周期、格式等说明信息 |
| **商业元数据** | 指标业务含义、主题分析目标、报表指标解释等信息 |
| **其他元数据** | 数据访问日志、数据装载日志等 |

## 管理意义

随着业务发展，业务线庞大起来，人员变更增多，没有元数据治理很难保证数据质量。元数据管理用于：

- 记录公司拥有什么数据
- 数据在哪里、由谁负责
- 数据值意味着什么
- 数据生命周期是什么
- 哪些数据需要保护安全性和隐私性
- 谁使用了数据，用于什么业务目的
- 数据质量怎么样

在电子商务场景中，元数据管理与[[电子数据交换EDI]]、单证格式标准、流程接口规范紧密结合，支撑在线支付、信用服务、现代物流等[[电子商务标准体系]]支撑体系的安全高效运行。

## 数据血缘关系

元数据管理的一个重要应用是支撑[[数据血缘关系]]分析。通过血缘分析实现数据融合处理的可追溯，确保数据从产生、ETL处理、加工、融合、流转到最终消亡的全过程可追踪。

在数据处理过程中，每个环节都可能影响数据质量。良好的元数据管理能够追溯问题源头，确保后续数据具有高质量的"基因"。
