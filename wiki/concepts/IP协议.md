# IP协议详解：网际层核心协议

## 定义

网际协议（Internet Protocol，IP）是[[TCP/IP 协议簇]]中最重要的协议之一，位于网际层，负责将数据报从源主机传送到目标主机。IP协议是一种不可靠、无连接的协议，只提供 best-effort（尽力而为）传输服务。

## IP数据报结构

IP数据报由首部和数据两部分组成：

- **固定首部**：20字节基本首部
- **可变首部**：0~40字节任选字段  
- **用户数据**：不超过65535字节

### 首部字段详解

| 字段 | 位数 | 说明 |
|------|------|------|
| 版本号 | 4位 | 协议版本，目前常用IPv4，正过渡到IPv6 |
| IHL | 4位 | IP头长度，以32位字计数，最小为5（即20字节） |
| 服务类型 | 8位 | 区分不同的可靠性、优先级、延迟和吞吐率 |
| 段总长度 | 16位 | 包含IP头在内的数据单元总长度（字节数） |
| 标识符 | 16位 | 唯一标识数据报的标识符 |
| 标志 | 3位 | 包括分段、重装配及禁止分段标志 |
| 段偏置值 | 13位 | 指明该段处于原来数据报中的位置 |
| 生存期 | 8位 | 用经过的路由器个数表示 |
| 协议 | 8位 | 上层协议（TCP或UDP） |
| 头校验和 | 16位 | 对IP头的校验序列，每经路由器重新计算 |
| 源地址 | 32位 | 源网络和主机地址 |
| 目的地址 | 32位 | 目标网络和主机地址 |
| 任选数据 | 可变长 | 发送者想要传输的任何数据 |

## 版本演进

IP协议有两个主要版本：

- **[[IPv4]]**：使用32位（4字节）地址，目前广泛使用但地址空间已接近枯竭
- **[[IPv6]]**：使用128位地址，是下一代互联网协议，正在逐步推广

## 协议特点


1. **不可靠性**：IP协议不保证数据报一定能到达目的地
2. **无连接性**：不需要事先建立连接
3. **Best-effort服务**：不保证顺序、不防止重复
4. **分段与重组**：当数据报大小超过网络最大传输单元（MTU）时进行分片传输

## 与其他协议的关系

IP协议与[[TCP/IP 协议簇]]中的其他协议紧密协作：

- **[[TCP协议]]**：面向连接的可靠传输，与IP配合工作
- **[[UDP协议]]**：无连接的传输，同样基于IP
- **[[ICMP协议]]**：网际控制消息协议，用于传输通信问题消息
- **[[ARP 和 RARP]]**：进行IP地址与物理地址的相互转换

## 技术要点

- 校验和计算：IP头中所有16位字进行1的补码相加，假设校验和字段本身为0
- 分片机制：标识符、标志和段偏置值字段用于分片和重装配
- 生存期：每经过一个路由器减1，为0时数据报被丢弃
- 地址分配：源地址和目的地址分别给网络和主机地址分配若干位

## 设计哲学

IP协议的设计遵循端到端原则和[[分组交换]]技术，将复杂功能放在端系统，核心网络保持简单。这种简化设计使得互联网具有很好的可扩展性和鲁棒性。
