# 灾难备份中心

## 定义

灾难备份中心（Disaster Backup Center）是指为保障信息系统在遭受灾难后能够快速恢复业务运行而建设的备选场地及相关配套设施。它是灾难恢复体系中的核心基础设施，承担着数据备份、系统切换和业务恢复的重要职能。

## 建设要求

灾难备份中心的建设和选择需要满足以下关键要求：

### 风险规避原则
灾难备份中心的选择和建设应根据[[风险分析]]的结果，避免与主中心同时遭受同类风险。这意味着在地理位置上应保持适当距离，确保区域性灾难（如地震、洪水）不会同时影响两个站点。

### 基础设施条件
- **交通条件**：应具有方便灾难恢复人员或设备到达的交通条件，确保在紧急情况下能够快速响应
- **通信资源**：具备数据备份和灾难恢复所需的通信设施
- **电力资源**：保障稳定可靠的电力供应

### 标准符合性
- 计算机机房应符合有关国家标准的要求
- 工作辅助设施和生活设施应符合[[灾难恢复规划]]目标的要求

### 资源共享原则
灾难备份中心应根据资源共享、平战结合的原则进行合理布局，在非灾难时期可作为其他用途，提高资源利用效率。

## 与灾难恢复体系的关系

灾难备份中心是支持[[灾难恢复规划]]中7个关键资源要素的重要载体，与以下概念密切相关：

- [[数据容灾]]：灾难备份中心通过数据备份系统实现数据的远程复制和保护
- [[应用容灾]]：在备份站点构建应用系统，实现业务的透明切换
- [[灾难恢复预案]]：中心需要建立相应的操作规程和应急预案
- [[RTO]]（恢复时间目标）：决定了备份中心需要具备的快速响应能力
- [[RPO]]（恢复点目标）：决定了数据备份的频率和实时性要求

## 日常运行管理

灾难备份中心的日常运行包括：
- 定期进行数据备份和验证
- 保持备用数据处理系统和备用网络系统处于正常状态
- 与主系统参数保持一致
- 建立技术支持组织和应急响应能力
- 定期进行演练和测试

## 关键等级

灾难备份中心的等级评定应与[[容灾技术]]的6个等级相对应：

| 等级 | 特征 |
|------|------|
| 第1级 | 基本支持 |
| 第2级 | 备用场地支持 |
| 第3级 | 电子传输和部分设备支持 |
| 第4级 | 电子传输及完整设备支持 |
| 第5级 | 实时数据传输及完整设备支持 |
| 第6级 | 数据零丢失和远程集群支持 |
