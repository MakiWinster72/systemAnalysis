# 图论基础算法

图论基础算法是计算机科学中用于处理图结构问题的经典算法集合。这些算法广泛应用于网络路由、资源调度、数据分析等领域。

## 算法分类

图论基础算法主要分为以下几大类：

### 1. 最短路径算法

最短路径问题是图论中的核心问题，用于求解两个顶点间权值总和最小的路径。代表算法包括：

- [[迪杰斯特拉算法]]（Dijkstra）：按路径长度递增次序产生最短路径，适用于无负权边的单源最短路径问题
- [[弗洛伊德算法]]（Floyd-Warshall）：动态规划算法，通过枚举中间节点求解任意两点间的最短路径
- [[贝尔曼-福特算法]]（Bellman-Ford）：可处理带负权边的最短路径问题，并能检测负权回路
- [[A*算法]]：启发式搜索算法，通过启发函数引导搜索方向，加快搜索速度
- [[约翰逊算法]]（Johnson）：结合贝尔曼-福特和迪杰斯特拉算法优点，处理含负权边的全源最短路径
- [[SPFA算法]]：贝尔曼-福特算法的改进版本，通过队列优化提升效率

### 2. 最小生成树算法

最小生成树算法用于在带权无向图中找到连接所有顶点且总权值最小的边集。代表算法包括：

- 普里姆算法（Prim）：采用贪心策略，逐步选择连接已选集合和未选集合的最小权边
- 克鲁斯卡尔算法（Kruskal）：按边权值从小到大排序，依次选择不形成环的最小权边
- 反向删除算法：按边权从大到小排序，逐步删除边直到图不再连通

### 3. 网络与最大流量

最大流量问题研究如何在容量受限的网络中找到最大传输能力。相关算法包括：

- [[网络与最大流量]]：求解从源点到汇点的最大运输能力

## 核心概念

### 顶点和边

图由顶点集V和边集E组成，表示为G=(V,E)。每条边可以有权值，表示距离、成本或容量等。

### 红点集与蓝点集

在最短路径算法中（如迪杰斯特拉算法），顶点被分为两类：
- **红点集（S）**：最短距离已确定的顶点
- **蓝点集（V-S）**：最短距离尚未确定的顶点

### 松弛操作

贝尔曼-福特等算法使用松弛操作更新节点的最短路径估计值：
```
如果 dis[u] + w(u,v) < dis[v]:
    dis[v] = dis[u] + w(u,v)
```

### 时间复杂度对比

| 算法类型 | 典型算法 | 时间复杂度 |
|---------|---------|------------|
| 单源最短路径（无负边） | Dijkstra | O(V²) 或 O(ElogV) |
| 全源最短路径 | Floyd | O(V³) |
| 含负权的最短路径 | Bellman-Ford | O(nm) |
| 最小生成树 | Prim/Kruskal | O(ElogV) |

## 算法选择指南

选择图论算法时需考虑以下因素：

1. **图类型**：是否有向、是否有环、是否有负权边
2. **问题类型**：单源还是全源最短路径
3. **性能要求**：时间复杂度和空间复杂度
4. **数据规模**：顶点数和边数的大小

## 应用场景

- 网络路由和通信：求解最优传输路径
- 交通规划：计算最短行车路线
- 资源调度：确定最大物流运输能力
- 数据分析：关系网络分析和社会网络研究
