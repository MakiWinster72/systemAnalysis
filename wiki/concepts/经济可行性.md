# 经济可行性评估

## 定义

经济可行性也称为**投资收益分析**或**成本效益分析**，是可行性研究的四个方面之一，主要评估信息系统建设项目的经济价值和投资回报。经济可行性通常被认为是项目的底线，是决定项目是否能够获得批准的关键因素。

在经济可行性分析过程中，系统分析师需要从[[系统逻辑模型]]出发，提出若干个系统解决方案（候选方案），对每个候选方案进行成本和效益分析，描述各方案的经济优点和缺点。这是[[可行性研究]]第五个步骤的核心任务。

## 核心评估内容

经济可行性分析主要从以下几个方面进行评估：

### 1. 建设成本

项目建设所需的一次性投资，包括：
- 硬件设备采购成本
- 软件开发或采购成本
- 系统集成成本
- 人员培训成本
- 项目实施与管理成本

### 2. 运行成本

系统投入运行后的持续性支出，包括：
- 人员维护成本
- 硬件维护与更新成本
- 软件维护与升级成本
- 场地与设施成本
- 能源消耗成本

### 3. 经济收益

项目建成后可能带来的经济收益，可从多个维度进行分类：

| 分类维度  | 类型     | 说明                         |
| ----- | ------ | -------------------------- |
| 收益来源  | 直接收益   | 系统运行直接产生的经济效益              |
|       | 间接收益   | 通过优化流程、减少损失等间接带来的收益        |
| 表现形态  | 有形收益   | 可以用货币精确计量的收益               |
|       | 无形收益   | 品牌形象提升、客户满意度提高等难以量化但有价值的收益 |
| 时间特征  | 一次性收益  | 一次性发生的收益                   |
|       | 非一次性收益 | 持续性、周期性的收益                 |
| 可量化程度 | 可定量收益  | 可以通过数据计算明确的收益              |
|       | 不可定量收益 | 难以用具体数值衡量的收益               |

## 转换成本的经济考量

系统转换涉及复杂的经济评估工作。根据[[系统转换策略]]的不同，转换成本存在显著差异：

| 转换策略       | 转换成本 | 风险成本 | 适用场景              |
| ---------- | ---- | ---- | ----------------- |
| [[直接转换策略]] | 最低   | 最高   | 新系统不复杂或现有系统完全不能使用 |
| [[并行转换策略]] | 较高   | 较低   | 需要充分验证新系统可靠性      |
| [[分段转换策略]] | 中等   | 中等   | 大型复杂系统的渐进式过渡      |

### 直接转换的成本特点

直接转换策略虽在人力和费用上最省，但需要特别考虑以下经济因素：

- **转换代价**：新旧系统之间的一次性转换投入较大
- **开发周期**：由于需要完整业务需求，开发周期长，一次性投资巨大
- **技术风险**：未经广泛使用的新技术平台具有不确定的成本风险
- **数据迁移成本**：旧系统积累的大量业务数据需要在转换时进行录入、转换、检查和重建

### 并行转换的成本特点

并行转换策略需要同时维持新旧系统运行一段时间，因此存在以下经济考量：

- **双倍运营成本**：新系统和现有系统并行工作期间，运营成本叠加
- **过渡期延长**：试运行阶段可能延长项目周期，增加总体投入
- **风险缓冲价值**：较低的转换风险可以避免未来可能的更大损失

### 数据迁移成本

无论采用哪种转换策略，[[数据迁移]]都是经济可行性分析的重要组成部分：

- 历史数据的完整性直接影响新系统的价值
- 数据迁移失败可能导致业务中断，造成经济损失
- 需要预留足够的[[项目管理计划]]和资源用于数据迁移工作

## 候选方案的经济评价方法

在可行性研究的第五个步骤中，对候选方案进行经济可行性评价时可以采用以下工具：

### 候选系统方案矩阵

候选系统方案矩阵是一种记录各个候选方案相同点和不同点的工具，可用于对比不同方案的经济特征，包括：
- 系统架构的性价比
- 数据处理方法的成本效率
- 数据存储方案的扩展成本
- 处理环境的运维费用

矩阵的行表示系统方案的特征，列表示候选系统方案，系统分析师应至少保留一个现有系统方案作为评估基准。

### 可行性分析矩阵

在列出候选系统方案矩阵后，根据可行性评价准则对候选系统方案进行分析和等级评定。可行性分析矩阵将经济可行性作为核心评价维度之一，对各候选方案的经济特征进行量化评分，便于横向比较和决策。

## 核心评估指标

经济可行性分析的核心是评估项目的投资回报能力，主要包括以下关键指标：

### 投资回收期（Payback Period）

投资回收期是指用系统方案产生的净现金收入回收初始全部投资所需的时间。对于投资者而言，**投资回收期越短越好**，可以减少投资风险。

根据是否考虑资金的时间价值，投资回收期分为两种：

| 类型 | 说明 | 考虑因素 |
|------|------|----------|
| 静态投资回收期 | 不考虑货币的时间价值 | 累计净现金流量 |
| 动态投资回收期 | 考虑资金时间价值 | 累计折现值 |

**静态投资回收期实用公式：**

$$T = \text{累计净现金流量开始出现正值的年份数} - 1 + \frac{|\text{上年累计净现金流量}|}{\text{当年净现金流量}}$$

**动态投资回收期实用公式：**

$$T_d = \text{累计折现值开始出现正值的年份数} - 1 + \frac{|\text{上年累计折现值}|}{\text{当年净现金流量折现值}}$$

### 投资回收率

投资回收率反映企业投资的获利能力：

$$\text{投资回收率} = \frac{1}{\text{动态投资回收期}} \times 100\%$$

该指标越高，说明投资获利能力越强。

### 投资收益率（Rate of Return on Investment）

投资收益率又称**投资利润率**，是指投资收益占投资成本的比率，反映投资的收益能力：

$$\text{投资收益率} = \frac{\text{投资收益}}{\text{投资成本}} \times 100\%$$

投资收益率与净现值率存在重要关系：

> **投资收益率 = 100% + 净现值率（NPVR）**

因此，投资收益率也称为**现值指数**。

## 评估标准

- **投资回收期**：越短越好，一般需要与行业平均水平或企业预期比较
- **投资收益率**：当投资收益率明显低于企业净资产收益率时，说明其投资是失败的，应改善投资结构和投资项目；而当投资收益率远高于一般企业净资产收益率时，则存在操纵利润的嫌疑，应进一步分析各项收益的合理性

## 局限性

在系统开发初期进行经济可行性分析时存在一定的局限性：

> 由于用户需求和候选系统方案还没有确定，成本不可能得到准确的估算。因此，此时的经济可行性分析只能**大致估算**系统的成本和收益，判断信息系统的建设是否值得。

这意味着早期的经济可行性分析更多是**初步判断**而非精确计算，需要在后续阶段随着需求和方案的明确进行修正。

## 与其他可行性的关系

经济可行性是整个可行性研究的核心维度之一，与其他三个可行性维度相互关联：

- **[[concepts/技术可行性]]**：技术方案的选择直接影响建设成本和运行成本
- **法律可行性**：合规性要求可能增加额外的成本投入
- **用户使用可行性**：培训成本和使用成本需要纳入经济可行性考量
- **[[系统转换策略]]**：转换策略的选择直接影响转换成本和风险成本

在[[系统规划与分析]]阶段，系统分析师需要综合考虑各维度的可行性，确保候选方案在经济、技术、法律和用户使用方面均具可行性。
