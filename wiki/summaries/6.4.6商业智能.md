# 商业智能概述

本章节介绍[[商业智能]]（Business Intelligence, BI）的基本概念及其与知识管理的关联。

## 隐性知识与显性知识的区别

知识可分为显性知识和隐性知识两大类：

| 显性知识 | 隐性知识 |
|---------|---------|
| 规范、系统 | 尚未或难以规范、零星 |
| 背后有科学和实证基础 | 背后的科学原理不甚明确 |
| 稳定、明确 | 非正式、难以捉摸 |
| 经过编码、格式化、结构化 | 尚未编码、尚未格式化、尚未结构化 |
| 用公式、软件编制程序、规律、法则、原则和说明书等方式表述 | 用诀窍、习惯、信念、个人特技等形式呈现 |
| 运用者对所用显性知识有明确认识 | 运用者对所用隐性知识可能不甚了解 |
| 易于储存、理解、沟通、分享、传递 | 不易保存、不易传递、不易掌握 |


## 知识管理工具

### 知识生成工具

包括**知识获取、知识合成和知识创新**三大功能。利用具有初步[[人工智能]]功能的搜索引擎和知识挖掘工具进行知识的自动获取，可将相关词句组合，帮助合成分散的创新观点。

### 知识编码工具

通过标准形式表现知识，使其便于共享和交流。作用在于将知识有效存储并以简明方式呈现给使用者。难点在于知识难以离散表现，且不断积累变化，难以清晰区分和分类。

### 知识转移工具

使知识能在企业内传播和分享。知识的价值在于流动和使用。知识流动存在三类障碍：**时间差异、空间差异和社会差异**。知识转移工具可根据障碍特点帮助消除阻碍。

## 商业智能的核心功能

商业智能的核心是**从业务数据中提取有用的信息，然后根据这些信息来采取明智的行动**。现代化业务操作产生的订单、库存、交易账目、通话记录和客户资料等数据，经过分析可增进对业务情况的了解，帮助管理者做出及时、正确的判断。

## 商业智能产品分类

商业智能产品及解决方案主要分为：

1. **[[数据仓库]]产品**
2. **数据抽取产品**
3. **[[OLAP]]产品**
4. **展示产品**
5. **整体解决方案**（集成以上产品）
