# 1.1.2 系统及相关理论

本节系统阐述了[[系统]]的基本概念、特性、理论体系及其应用。

## 系统的定义

**系统**是由相互联系、相互依赖、相互作用的事物或过程组成的具有整体功能和综合行为的统一体。从数学角度看，系统是一个集合，由许多相互作用、相互依存的事物（集合元素）为达到某个目标而组成。

## 系统的9大特性

1. **整体性**：元素按一定原则有序排列组成系统，产生特定功能。
2. **层次性**：系统和元素是相对概念，系统可成为更高一级系统的子系统。
3. **目的性**：任何系统都有一定的目的或目标。
4. **稳定性**：开放系统具有自我稳定能力，能自我调节恢复有序状态。
5. **突变性**：系统通过失稳从一种状态进入另一种状态的剧变过程。
6. **自组织性**：开放系统自发组织，从无序到有序、从低级有序到高级有序。
7. **相似性**：系统结构、存在方式和演化过程具有共同性，源于世界的物质统一性。
8. **相关性**：元素有明确边界且相互联系，是具体的实在联系。
9. **环境适应性**：系统与环境发生物质和能量交换。

## 系统论的任务

系统论的任务在于利用系统特点去控制、管理、改造或创造系统，使系统发展更符合人类需要。作用包括：
- 改变人类思维方式（从传统分析到系统分析）
- 提供科学的理论和方法
- 形成统一的系统科学体系（贝塔朗菲的狭义与广义系统论）

## 系统理论的8大基本原理

| 原理 | 核心内容 |
|------|----------|
| 整体性原理 | 元素按一定方式相互联系产生整体性 |
| 整体突变原理 | 系统产生元素总和没有的新性质（非加和原理） |
| 层次性原理 | 系统组织表现出等级秩序 |
| 开放性原理 | 系统与环境交换物质、能量、信息 |
| 目的性原理 | 系统发展趋向预先确定的状态 |
| 系统环境互塑共生原理 | 功能和污染、资源和压力的相互作用 |
| 秩序原理 | 有序与无序两种形态并存 |
| 生命周期原理 | 系统从产生到消亡的演化过程 |

## 信息系统

信息系统是接受输入数据、通过加工处理产生信息的系统。**以计算机为基础的信息系统**由三要素构成：

> 管理模型 + 信息处理模型 + 系统实现条件 → [[信息系统]]

- **管理模型**：系统服务对象领域的专门知识及分析处理模型
- **信息处理模型**：系统处理信息的结构和方法（信息获取、存储、传输等）
- **系统实现条件**：技术、环境等支撑条件

## 相关概念

本节还简要介绍了信息与数据、知识的关系：
- **信息与数据**：数据是信息的原材料，信息是经过加工、被解释的数据
- **信息与知识**：知识是经过加工的信息，具有推理得出的新性质
