# 差错控制

本节介绍了数据通信中的两种主要差错类型及其控制方法。

## 差错的分类

通信过程中的差错可分为两类：

- **随机错误**：由热噪声引起，影响个别位，具有断续存在的特点
- **突发错误**：由冲击噪声（如雷电、电磁干扰）引起，影响一个位串，具有局部性特点

## 奇偶校验检错码

奇偶校验是最简单的检错方法，在7位ASCII代码后增加一位，使码字中1的个数为奇数（奇校验）或偶数（偶校验）。这种方法只能对付少量随机错误。

**校验和方法**可用于检测突发性位串出错：将数据块中每个字节当作二进制整数，按模256相加，把结果作为校验字节发送。接收端用同样的方法计算校验和进行比较。

## 海明码

海明码是一种既能检测又能纠正错误的编码方法，其核心概念是[[海明距离]]——一个码字变成另一个码字必须改变的最小位数。

**海明距离与纠错能力的关系**：
- 若任意两个码字之间的海明距离为d，则所有小于等于d-1位的错误都可以检查出来
- 所有小于d/2位的错误都可以纠正

海明码的实现方式是将码字各位编号，按二进制表示分配奇偶校验位（1、2、4、8等位置）。接收端通过检测哪些校验位的奇偶性错误，将错误位编号相加即可定位错误位置。

## 循环冗余校验码（CRC）

CRC是一种具有很强检错能力的循环码，易于用硬件实现，广泛应用于局域网。

CRC的实现基于移位寄存器结构，包含k位寄存器和异或门反馈回路。其数学基础是多项式除法：
- 数据位视为数据多项式D(x)的系数
- 反馈回路对应生成多项式G(x)
- 实际传送码字为：F(x) = x^k·D(x) + R(x)（R(x)为余数）

**国际标准生成多项式**：
- CRC-CCITT：G(x) = x^16 + x^12 + x^5 + 1
- CRC-16：G(x) = x^16 + x^15 + x^2 + 1
- CRC-32：G(x) = x^32 + x^26 + x^23 + x^22 + x^16 + x^12 + x^11 + x^10 + x^8 + x^7 + x^5 + x^4 + x^2 + x + 1（常用于局域网）
