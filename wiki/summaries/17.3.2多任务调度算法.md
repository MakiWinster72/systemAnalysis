# 多任务调度算法

## 概述

本文档系统介绍了嵌入式实时系统中的多任务调度算法，涵盖算法分类、核心调度策略及可调度性分析方法。

## 中断与系统响应时间

- **中断延迟时间**：从中断发生到系统获知的时间，受最大关中断时间影响
- **中断响应时间**：中断发生到开始执行中断服务例程的时间
- **中断恢复时间**：中断服务例程结束到恢复被中断代码的时间
- **系统响应时间**：发出处理请求到系统应答的时间，即调度延迟

## 调度算法分类

调度算法根据以下准则分类：

| 分类维度 | 类型 |
|---------|------|
| 时限性质 | 软时限算法 / 硬时限算法 |
| 周期性 | 周期性算法 / 非周期性算法 |
| 可抢占性 | 可抢占算法 / 非抢占算法 |
| 优先级确定 | 静态算法 / 动态算法 |
| 处理器数量 | 单处理器调度 / 多处理器调度 |
| 调度时机 | 在线调度 / 离线调度 |

## 核心调度算法

### 1. 基于优先级的抢占调度

- **静态优先级**：任务优先级在编译时确定，运行期间不变
- **动态优先级**：任务优先级可由内核动态更改，实现灵活的实时响应

### 2. 单调速率调度算法 (RMS)

[[concepts/RMS调度算法]] — Rate Monotonic Scheduling 是静态固定优先级算法：
- 任务优先级与周期呈单调函数关系
- **周期越短，优先级越高**
- 是静态调度算法中最有效的算法

**RMS定理**：n个任务的系统满足硬实时条件的充分条件为：
```
Σ(Ei/Ti) < n(2^(1/n) - 1)
```

当 n→∞ 时，该上限趋近于 **69.3%**，工程实践中 CPU 利用率应控制在 **60%~70%** 之间。

### 3. 时间轮转调度

为相同优先级任务提供均等 CPU 时间片：
- 时间片过大失去轮转意义
- 时间片过小导致频繁切换，开销增大
- 通常采用**基于优先级的抢占式时间轮转调度**

### 4. 截止时间优先调度 (EDF)

[[concepts/EDF调度算法]] — Earliest Deadline First 是动态优先级算法：
- 执行时限越靠近，优先级越高
- 可调度性上限为 **100%**（CPU 利用率最高）
- 实现难度较大，调度开销较高

### 5. 分区 APPS 调度

面向综合化模块化航空电子系统 (IMA) 的静态调度算法：
- 将处理器时间划分为独立时间片
- 采用**时间优先调度 (TPS)**
- 调度单元是分区，分区无优先级
- 闲置时间片采用优先级调度 (APPS)

## 可调度性分析

[[concepts/实时系统可调度性分析]] 方法：通过计算任务 CPU 利用率，与理论上限比较判断系统是否满足时限要求。常用方法包括：
- **速率单调分析 (RMA)**：基于 RMS 定理
- **处理器利用率分析法**：基于 EDF 充分必要条件
