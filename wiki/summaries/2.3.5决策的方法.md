# 决策的方法

## 核心内容

本节介绍了[[决策]]的定量计算方法，重点讲解了[[线性规划]]的图解法及其应用。

## 主要内容

### 1. 决策实施与反馈

决策不仅是选择方案，还包括制订执行计划、资源预算。实施过程需要跟踪、监督和反馈，确保方案实现预定目标并及时调整。

### 2. 决策的动态过程

决策是一个动态过程，分为四个阶段并可循环反馈：
- 情报活动阶段
- 设计活动阶段
- 抉择活动阶段
- 实施活动阶段

### 3. 定量计算方法

通过数学模型和技术对决策因素进行量化分析，常见方法包括：
- [[线性规划]]
- 成本效益分析
- 效用分析
- 模拟仿真
- [[决策树分析]]

### 4. 线性规划求解方法

解[[线性规划]]问题最常用的两种方法：
- **图解法**：简单直观，适用于变量数≤3的情况
- **单纯形法**：适用于变量数>3的复杂问题

### 5. 线性规划数学模型

典型[[线性规划]]问题包含三个要素：

**目标函数**：确定优化方向
```
max z = 2x₁ + 3x₂
```

**约束条件**：资源限制
```
x₁ + 2x₂ ≤ 8
4x₁ ≤ 16
4x₂ ≤ 12
x₁, x₂ ≥ 0
```

**决策变量**：待确定的产量

### 6. 图解法应用示例

工厂排产问题演示图解法步骤：
1. 将约束条件转化为半平面
2. 在直角坐标系中绘制可行域（阴影区域）
3. 绘制等值线，平行移动至最优解
4. 确定最优解坐标为(4, 2)，最大利润z=14

## 关键概念

- **[[目标函数]]**：需优化的数学表达式
- **约束条件**：决策变量必须满足的限制
- **可行域**：满足所有约束条件的区域
- **等值线**：目标函数值相同的点的轨迹
- **最优解**：使目标函数达到最优值的可行解

## 总结

本节系统介绍了[[决策]]中的[[线性规划]]定量计算方法，通过工厂排产实例展示了图解法的完整应用流程，从问题分析、数学建模、图解法求解到最优解验证，为复杂决策问题提供了量化分析工具。
