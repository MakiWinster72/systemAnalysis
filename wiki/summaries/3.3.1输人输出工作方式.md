## 输入输出工作方式

### 概述

输入输出系统（I/O系统）是计算机系统的重要组成部分，由I/O设备、I/O接口和I/O控制管理软件组成，实现计算机内部与外部设备之间的数据交换。

### 五种I/O工作方式

I/O系统有5种不同的工作方式，从简单到复杂依次为：

#### 1. 程序控制方式

由CPU执行I/O程序来实现数据传送，分为两种：

- **无条件传送方式**：I/O端口始终准备就绪，CPU直接访问。软硬件简单，但要求时序配合精确，仅用于简单开关量控制。
- **程序查询方式**：CPU主动查询外设工作状态，若未就绪则循环等待。方法简单、硬件开销小，但[[CPU]]利用率低，I/O能力不高。

#### 2. 程序中断方式

当计算机执行程序时遇到异常情况或特殊请求，CPU暂时中止现行程序（保护现场），转去处理紧迫事件，处理完毕后自动返回（恢复现场）。

**中断过程5阶段**：中断请求 → 中断判优 → 中断响应 → 中断处理 → 中断返回 #背诵

**多中断源处理方法**：多中断信号线法、中断软件查询法、雏菊链法、总线仲裁法、中断向量表法

与程序控制方式相比，[[中断]]方式因CPU无须等待而提高了效率。

#### 3. DMA工作方式

DMA（Direct Memory Access）即直接存储器访问，用于主存与外设间的高速批量数据交换。使用DMA控制器（DMAC）控制和管理数据传输。

**DMAC获取总线的方式**：
- CPU停止访问主存法（暂停方式）
- 存储器分时法（共享方式）
- 周期挪用法（周期窃取方式）

**DMA特点**：
- 主存与CPU固定联系脱钩
- 数据块传送时地址确定、计数由硬件直接实现
- 主存开辟专用缓冲区
- 传送速度快，CPU和外设并行工作
- 传送前后需通过程序和中断进行预处理与后处理

#### 4. 通道方式

[[通道]]是一种高级I/O控制部件，利用软件手段实现对I/O的控制和传送，使主机和外设的并行工作程度更高，但仍受CPU管理。

**三种通道类型**：
- **字节多路通道**：简单共享通道，连接多台低速设备，以字节交叉方式传送
- **选择通道**：高速通道，一段时间内只允许一台设备独占通道
- **数组多路通道**：结合字节多路和选择通道特点，有多个子通道，既能多路并行操作，又有很高数据传输速率

#### 5. I/O处理机

又称外围处理机，具有丰富的指令系统和完善的[[中断]]系统，专用于大型高效计算机系统。

**I/O处理机功能**：
- 完成通道全部功能
- 码制转换、数据校验和校正
- 故障处理、文件管理
- 诊断和显示系统状态
- 处理人机对话
- 网络或远程终端连接
- 数据库和知识库管理

### 总结

从程序控制方式到I/O处理机，体现了I/O技术逐步解放CPU、提高并行性的发展过程。越复杂的I/O方式，并行度越高，但需要更复杂的硬件和软件支持。
