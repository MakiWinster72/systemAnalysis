# .NET开发框架与Java EE框架概述

本章节介绍了企业级应用开发中两大主流开发框架体系：**Java EE框架**和**.NET框架**。

## Java EE框架

### Spring框架
Spring是解决企业应用开发复杂性的开源框架，其核心优势在于**分层架构**设计。Spring通过**依赖注入（Dependency Injection）**机制，在运行期间为组件配置所需资源，无须在编写代码时就指定，从而大幅降低组件间的**耦合性**。开发人员可以面向接口编程，无须知道实现类的具体名称，通过修改配置文件即可切换底层实现类，显著改善了代码的**可重用性**。

### Struts框架
Struts是Apache开发的基于**MVC模式**的企业级Web应用开源框架，整合了Servlet、JSP、自定义标签和信息资源。框架通过struts-config.xml配置文件将模型、视图和控制器三部分联系起来，采用标记将逻辑处理代码从页面分离，简化页面开发。

### Hibernate框架
Hibernate是开源**对象关系映射（ORM）**框架，对JDBC进行轻量级封装，使Java程序员可使用对象编程思维操作数据库。其查询语言HQL是SQL的面向对象扩展，使用XML文件(.hbm.xml)实现Java类与数据库表的映射。

### JSF框架
JSF（Java Server Faces）是构建Web应用的标准Java框架，提供可扩展UI组件、页面导航、数据验证转换、自动化Bean管理、事件处理和国际化的内置支持。采用**Model-View-Controller**架构：Model使用JavaBean/EJB实现业务逻辑，View由JSF标签构成的JSP页面组成，Controller由FacesServlet和配置文件组成。

## .NET框架

.NET框架由微软开发，致力于**敏捷软件开发**、快速应用开发、**平台无关性**和网络透明化。
