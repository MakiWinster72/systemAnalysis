# Web应用系统数据存储

## 概述

本文档系统介绍了Web应用系统中常用的数据存储技术和架构组件，涵盖通信协议、缓存策略、云存储服务、内容分发网络、负载均衡以及消息队列等关键技术。

## 通信协议

### Session与状态管理

HTTP协议本身具有**无连接、无状态**的特性。对于交互型Web应用，需要借助Session（会话）来区分并发用户及关联请求。Session跟踪通常采用以下两种方法：
- **URL重写**：将Session ID嵌入URL参数
- **Cookies**：在客户端存储Session标识

### 实时传输协议

- **RTP（实时传送协议）**：IETF于1996年公布的网络传输协议，详细定义Internet上音频和视频数据包格式。常用于流媒体系统、视频会议和IP电话。
- **RTSP（实时流传输协议）**：TCP/IP体系中的应用层协议，用于控制音频或视频的实时发送，位于RTP和RTCP之上。

### 邮件传输协议

- **SMTP（简单邮件传输协议）**：提供可靠有效的电子邮件传输协议，建立在TCP服务之上，支持"SMTP邮件中继"。
- **POP3（邮局协议版本3）**：用于电子邮件接收，使用TCP 110端口，允许用户将邮件存储到本地主机。

## 数据存储技术

### 缓存系统

缓存系统是本地数据存储，有助于快速访问数据而无需每次联系数据库。缓存系统有四种设计模型：

1. **应用程序服务器缓存**：单个节点的内存中缓存
2. **全局缓存**：所有节点访问单个缓存空间
3. **分布式缓存**：缓存分布在多个节点上，使用一致哈希函数路由请求
4. **CDN（内容交付网络）**：用于交付大量静态数据

### 云存储

云存储通过网络中大量存储设备协同工作，对外提供数据存储和业务访问功能。主流云存储服务包括：

- **Amazon S3**：AWS环境中的云存储解决方案，具有高可用性、高扩展性，数据存储在"存储桶"中
- **Azure Cloud Storage**：提供99.95%正常运行时间，0.18美元/GB/月
- **谷歌云存储**：0.02美元/GB/月，多地区可用

### 内容交付网络（CDN）

CDN是安装在各地理位置的服务器网络，通过缓存内容加速用户访问。主流CDN服务：

- **CloudFront**：AWS的CDN服务，与EC2、Lambda、S3等深度集成
- **Azure CDN**：微软Azure平台提供，低延迟易配置
- **Cloud CDN**：谷歌的内容交付网络
- **CloudFlare**：提供DNS服务，充当反向代理

## 负载均衡

负载均衡器根据可用性或预定义策略将流量分布到不同服务器。实现方式分为：

- **软件负载均衡**：四层（LVS、Haproxy）和七层（Haproxy、Nginx）
- **硬件负载均衡**：NetScaler、F5、Radware、Array等商用设备

软件四层交换高并发但不支持正则动静分离；七层交换功能丰富但性能较低。

## 消息队列

消息队列作为缓冲区，异步存储消息，促进微服务间通信。在微服务架构中，软件组件通过[[RESTful API]]相互通信，消息队列协调块之间的通信，提供可伸缩性、解耦和可靠性。

基于消息队列的点对点模式属于有独立派遣模块设计，消息生产者发送到Queue，消息消费者取出并消费消息。
