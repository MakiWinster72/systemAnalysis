# 事件与概率基础

## 概述

本章节出自《系统分析师教程（第2版）》第2章"数学与工程基础"，系统讲解了[[古典概率]]模型中事件与概率的基本概念、运算定律及其性质，为系统分析师提供数学思维与分析能力的基础训练。

## 核心概念

### 随机试验与随机事件

- **随机试验**：在相同条件下重复进行，每次结果不可预知的试验
- **随机事件（事件）**：在随机试验中可能发生也可能不发生的事件，简称事件
- **样本点**：随机试验中每一个可能的试验结果
- **样本空间（Ω）**：样本点的全体
- **必然事件**：包含所有样本点的事件，即Ω
- **不可能事件（∅）**：不包含任何样本点的事件

### 事件的包含与相等

- **子事件**：若事件A发生必然导致事件B发生，记作A⊂B或B⊃A
- **相等事件**：若A⊂B且B⊂A，则A=B

## 事件运算

### 1. 和事件（并事件）

事件"A₁, A₂, ..., Aₙ中至少有一个发生"称为和事件，记作⋃ᵢ₌₁ⁿAᵢ。

**运算定律**：
- 交换律：A∪B = B∪A
- 结合律：A∪(B∪C) = (A∪B)∪C
- 幂等律：A∪A = A
- 同一律：A∪Ω = Ω
- 零律：A∪∅ = A
- 吸收律：若A⊂B，则A∪B = B

### 2. 积事件（交事件）

事件"A₁, A₂, ..., Aₙ同时发生"称为积事件，记作⋂ᵢ₌₁ⁿAᵢ。

**运算定律**：
- 交换律：A∩B = B∩A
- 结合律：A∩(B∩C) = (A∩B)∩C
- 幂等律：A∩A = A
- 同一律：A∩Ω = A
- 零律：A∩∅ = ∅
- 吸收律：若A⊂B，则A∩B = A

### 3. 差事件

事件"A发生且B不发生"称为A与B的差事件，记作A-B。

**运算定律**：
- A - A = ∅
- A - ∅ = A
- A - Ω = ∅
- A∩(B-C) = (A∩B)-(A∩C)
- A-(B∪C) = (A-B)∩(A-C)
- A∩(B-A) = ∅
- A∪(B-A) = A∪B

### 4. 逆事件（对立事件）

样本空间Ω减去事件A，即Ω-A称为A的逆事件或对立事件，记作Ā。A发生当且仅当Ā不发生。

**运算定律**：
- Ā = A（双重否定）
- A∪B = Ā∩B̄
- A∩B = Ā∪B̄
- A-B = A∩B̄ = A-(A∩B)
- A∪(Ā∩B) = A∪B
- A∩(Ā∪B) = A∩B

### 5. 互斥事件

若A与B不可能同时发生，则称A与B为互斥事件（互不相容事件）。

> **重要性质**：逆事件一定是互斥事件，但互斥事件不一定互为逆事件。

## 概率基础

### 概率的定义

在不变条件下重复做n次试验，事件A在n次试验中发生m次。当n很大时，频率m/n稳定地在数值p附近摆动，则p为事件A的[[概率]]，记作P(A)=p。

### 概率的基本性质

1. P(∅) = 0，P(Ω) = 1
2. 对任何事件A：0 ≤ P(A) ≤ 1
3. P(Ā) = 1 - P(A)
4. P(A-B) = P(A) - P(AB)
5. 当B⊂A时：P(A-B) = P(A) - P(B)

> **注意**：概率为0的事件不一定是不可能事件，概率为1的事件也不一定是必然事件。

### 条件概率

当P(A) > 0时，在事件A发生的条件下事件B发生的[[条件概率]]为：

P(B|A) = P(AB) / P(A)
