## 随机变量及其分布

### 概述
本节介绍概率论中最重要的概念——随机变量。随机变量是对随机现象的度量化表示，通过将样本空间中的每个样本点映射为实数值，实现随机事件的数学描述。

### 1. 分布函数

设随机试验的样本空间为Ω，对于每一个样本点ω∈Ω，都有唯一的实数ξ(ω)与之对应，则称ξ(ω)为**随机变量**。

**概率分布函数**定义为：
```
F(x) = P(ξ ≤ x), -∞ < x < +∞
```

分布函数具有以下性质：
- 0 ≤ F(x) ≤ 1
- 单调非递减：若x₁ < x₂，则F(x₁) ≤ F(x₂)
- 右连续：F(x+0) = F(x)
- 极限性质：lim F(x) = 0 (x→-∞), lim F(x) = 1 (x→+∞)

### 2. 离散型随机变量

若随机变量只能取有限个或可数个数值{x₁, x₂, ..., xₖ, ...}，则称为**离散型随机变量**。

概率分布：pₖ = P(ξ = xₖ)，满足：
- pₖ ≥ 0
- Σpₖ = 1 (k=1,2,...)

### 3. 连续型随机变量

若存在非负可积函数p(x)，使得：
```
F(x) = ∫p(t)dt, -∞ < x < +∞
```
则称ξ为**连续型随机变量**，p(x)称为**分布密度函数**。

性质：
- p(x) ≥ 0, 且∫p(x)dx = 1
- 分布函数F(x)在(-∞, +∞)上连续
- 若p(x)在x处连续，则F'(x) = p(x)

### 4. 二维随机变量

**二维离散型**：若(ξ, η)只能取有限对或可数对数值，概率分布为pᵢⱼ = P(ξ=xᵢ, η=yⱼ)。

**二维连续型**：若存在非负可积函数p(x,y)，使得：
```
F(x,y) = ∬p(u,v)dudv
```
则p(x,y)为**联合概率密度函数**。

### 5. 随机变量的数字特征

**数学期望**反映了随机变量的取值中心：

- 离散型：Eξ = Σxₖpₖ
- 连续型：Eξ = ∫xp(x)dx

性质：E(C) = C（常数），E(kξ) = kE(ξ)
