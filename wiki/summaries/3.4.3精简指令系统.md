# 精简指令系统（RISC）

精简指令系统计算机（Reduced Instruction Set Computer, RISC）是计算机体系结构中的重要设计理念，通过简化指令途径使计算机结构更加简单合理，从而减少指令执行周期数，提高运算速度。

## RISC的主要特点

RISC具有以下七个核心特征：

1. **指令数量少**：优先选取使用频率最高的简单指令和常用指令，避免复杂指令。仅提供LOAD和STORE两条指令访问存储器，其余操作均在CPU寄存器间进行。

2. **寻址方式少**：通常只支持寄存器寻址、立即数寻址和相对寻址三种方式。

3. **指令格式规整**：指令长度固定，格式种类少，各字段划分一致，译码容易。

4. **硬布线逻辑控制**：采用组合逻辑构建控制器，提高指令执行速度。

5. **单周期执行与流水线**：大部分指令在一个机器周期内完成，利用流水线技术提升性能。

6. **优化编译器**：精简指令集使编译工作简化，易于生成高效机器代码。

7. **大量通用寄存器**：CPU中通用寄存器数量多（一般32个以上，多者可达上千个）。

大多数RISC采用独立的指令Cache和数据Cache，实现取指令与取数据并行。

## RISC的核心思想

RISC的设计基于执行时间公式：**P = I × CPI × T**

- **I（指令条数）**：RISC的I值比CISC长约20%~40%，因为复杂指令需要多条简单指令替代。
- **CPI（每条指令平均周期数）**：RISC大多数指令单周期执行，CPI略大于1；CISC平均CPI为4~10。
- **T（周期时间）**：CISC的T通常是RISC的3倍左右。

综合以上，RISC处理速度比同规模CISC提高3~5倍，关键在于CPI的减小。

减小CPI是硬件与软件协同努力的结果：硬件方面采用硬布线逻辑、减少指令种类、固定指令格式、LOAD/STORE结构、多级流水线；软件方面强调优化编译技术。

## RISC的关键技术

1. **延迟转移技术**：在转移指令后插入有效指令，使流水线不断流。

2. **指令取消技术**：转移指令和数据变换指令可决定后续指令是否取消，被取消指令相当于空操作。

3. **重叠寄存器窗口技术**：将大寄存器堆划分为多个窗口，每个过程使用相邻三个窗口和一个公共窗口，相邻过程共用窗口传递参数和结果。

4. **指令流调整技术**：编译器分析数据流和控制流，调整指令序列，消除数据相关，保持流水线高效运行。

5. **硬件为主、固件为辅**：主要采用硬布线逻辑实现指令系统，必需的复杂指令可用固件实现。

## RISC与CISC的关系

实际商品化的RISC并非纯粹RISC，在保持RISC基本特色的同时，还需辅以浮点运算、十进制运算等复杂指令，实现[[CISC]]与RISC的完美结合。
