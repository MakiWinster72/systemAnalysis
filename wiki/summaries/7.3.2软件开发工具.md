# 软件开发工具总结

## 1. ICASE（集成计算机辅助软件工程）

ICASE是第三代软件开发环境，集成方式经历了三个阶段：
- **点到点数据转换**（早期CASE）
- **公共用户界面**（第二代CASE）
- **信息库方式**（当前主流）

ICASE提供三类工具集：
- **垂直工具集**：支持软件生命周期各阶段
- **水平工具集**：支持不同软件开发方法
- **开放工具槽**：连接新工具

ICASE的终极目标是实现**应用软件的全自动开发**，从需求规格说明书自动生成可用软件。

## 2. 软件工具的分类

按功能分为三类：

| 类型 | 功能 | 包含工具 |
|------|------|----------|
| **软件开发工具** | 辅助开发活动 | 需求分析工具、设计工具、编码与排错工具 |
| **软件维护工具** | 辅助维护活动 | 版本管理工具、文档分析工具、逆向工程工具、再工程工具 |
| **软件管理与支持工具** | 辅助管理与支持 | 项目管理工具、配置管理工具、软件评价工具 |


## 3. 开发工具的选择

选择软件开发工具主要考虑：
- **功能**：设计模式、对象结构支撑
- **易用性**：学习曲线、用户体验
- **稳健性**：稳定性、可靠性
- **硬件要求和性能**
- **服务和支持**

两个决定性因素：**最终用户需求**和**开发人员偏好**。开发工具的比较没有绝对标准，需针对具体环境评价。

## 4. 快速开发工具（RAD）

RAD工具主要包括：
- 数据库编程语言
- 界面生成器
- 报告生成器

采用**可视化技术**，通过集成细粒度可复用构件来构造软件。常用工具包括Microsoft Visual Studio.NET、Sun Java Studio Creator等。

## 5. CMM软件能力成熟度模型

CMM将软件过程成熟度分为5个等级：

1. **初始级**：无秩序、混乱的过程
2. **可重复级**：建立基本项目管理流程
3. **已定义级**：过程标准化、文档化
4. **可管理级**：定量认识和控制
5. **优化级**：持续改进

每个等级包含若干**关键过程域（KPA）**，由关键实施活动（KP）组成。

## 6. CMMI能力成熟度模型集成

CMMI融合多种模型，提供两种表示法：

| 表示法 | 特点 |
|--------|------|
| **阶段式模型** | 沿袭CMM的5个成熟度等级，18个过程域 |
| **连续式模型** | 24个过程域按功能分为4组：过程管理、项目管理、工程、支持 |


两种方法逻辑等价，评估结论基本一致。
