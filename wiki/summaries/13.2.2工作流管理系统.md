# 13.2.2 工作流管理系统

## 概述

工作流管理系统（Workflow Management System，WFMS）通过软件定义、创建工作流，并管理其执行。它运行在一个或多个工作流引擎上，这些引擎解释对过程的定义，并与工作流的参与者相互作用，根据需要调用其他IT工具或应用。

## 基本功能

WFMS将业务流程中工作如何组织与协调的规则抽象出来，其基本功能体现在三个方面：

1. **对工作流进行建模**：定义工作流，包括具体的活动和规则等，所创建的模型是同时可以被人和计算机所"理解"的
2. **工作流执行**：遵循工作流模型来创建和执行实际的工作流
3. **业务过程的管理和分析**：监控和管理执行中的业务，例如进度完成情况、数据所处状态、工作分配与均衡情况等

## 工作流参考模型（WRM）

工作流参考模型包含6个基本模块和5个接口标准：

### 六个基本模块

| 模块 | 说明 |
|------|------|
| 工作流执行服务 | WFMS的核心模块，负责创建和管理流程定义，创建、管理和执行流程实例 |
| 工作流引擎 | 为流程实例提供运行环境，解释执行流程实例的软件模块 |
| 流程定义工具 | 管理流程定义的工具，通过图形方式定义复杂流程 |
| 客户端应用 | 通过请求方式与工作流执行服务交互，面向最终用户的界面 |
| 调用应用 | 被工作流执行服务调用的应用 |
| 管理监控工具 | 监控和管理工作流执行 |

### 五个接口标准

1. 工作流定义交换接口（接口一）
2. 工作流客户端应用接口（接口二）
3. 调用应用接口（接口三）
4. WFMFS互操作接口（接口四）
5. 系统管理和监控接口（接口五）

## 相关概念

- **活动参与者**：执行活动的流程参与者
- **活动所有者**：有权整体控制流程实例执行过程的参与者，通常是流程发起人
- **工作项**：代表流程实例中活动的参与者将要执行的工作

## 应用场景

将考勤管理、内部信息交流、工作日报或周报处理等工作流管理模块集成在一个软件中，即可得到WFMS，这类WFMS即OA系统。
