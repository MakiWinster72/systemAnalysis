# 数据挖掘概述

## 概述

数据挖掘与传统数据分析的本质区别在于：**在没有明确假设的前提下挖掘信息、发现知识**。

## 三个核心特征

数据挖掘所得到的信息应具备三个特征：

1. **先前未知** — 挖掘出不能靠直觉发现的信息，甚至是违背直觉的知识
2. **有效** — 信息具有实际应用价值
3. **可实用** — 可用于指导决策和实践

> 挖掘出的信息越是出乎意料，就可能越有价值。

## 数据挖掘体系结构

数据挖掘体系结构包含七个核心组件：

```
┌─────────────────┐
│ 知识发现系统管理器 │ ← 控制并管理整个知识发现过程
└────────┬────────┘
         │
┌────────▼────────┐
│     知识库      │ ← 存储元数据、规则、数据层次
└────────┬────────┘
         │
┌────────▼────────┐
│  数据访问接口   │ ← 利用SQL从数据仓库提取数据
└────────┬────────┘
         │
┌────────▼────────┐
│    数据选择     │ ← 确定抽取数据的结构
└────────┬────────┘
         │
┌────────▼────────┐
│  知识发现引擎   │ ← 抽取数据元素间的模式和关系
└────────┬────────┘
         │
┌────────▼────────┐
│    发现评价     │ ← 寻找关注性的数据模式
└────────┬────────┘
         │
┌────────▼────────┐
│    发现描述     │ ← 保存发现信息，辅助决策
└─────────────────┘
```

## 组件详解

| 组件 | 功能 |
|------|------|
| [[知识发现系统管理器]] | 控制并管理知识发现过程，录入知识库信息 |
| [[知识库]] | 存储元数据、关键数据属性、规则和数据层次 |
| 数据访问接口 | 使用SQL查询语言，结合元数据指导数据提取 |
| 数据选择 | 确定从数据仓库中需要抽取的数据及其结构 |
| 知识发现引擎 | 将抽取算法作用于数据，发现模式与关系 |
| 发现评价 | 分析员筛选关注性的数据模式 |
| 发现描述 | 保存发现信息，辅助[[决策支持]] |
