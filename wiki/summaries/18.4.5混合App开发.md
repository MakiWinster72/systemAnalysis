# 混合App开发总结

## 概述

混合开发是一种结合[[原生开发]]和[[HTML5]]开发的技术，取长补短。它主要以JS+Native两者相互调用为主，从开发层面实现"一次开发，多处运行"的机制。

## 核心特点

### 优点

1. **一次开发，多处运行**：减少开发成本和维护成本
2. **兼具优势**：既有[[Native App]]的良好用户体验，又有[[Web App]]的低成本跨平台优势
3. **可集成第三方SDK**：扩展功能丰富
4. **可使用原生API**：访问设备硬件功能
5. **可使用Web技术**：便于前端开发者参与

### 缺点

1. **性能问题**：不如纯原生应用
2. **依赖WebView**：需要容器支持
3. **交互局限**：难以实现复杂交互效果

## 常用开发框架

- **Ionic**：基于AngularJS和Cordova，提供丰富UI组件
- **React Native**：Facebook开源框架，使用JavaScript和React语法
- **Flutter**：Google推出的跨平台框架

## 案例分析

### 去哪儿网网页App

- **技术栈**：React Native + Redux + Ant Design Mobile + Node.js + Express + MongoDB
- **开发周期**：6个月（需求分析1月，开发3月，测试上线2月）
- **功能**：用户管理、景点查询、酒店预订、路线规划、旅游攻略分享

### Uber混合应用

- **技术栈**：Ionic + AngularJS + Cordova + Node.js + MongoDB
- **背景**：解决多操作系统兼容性和应用体积过大问题
- **实现方式**：原生代码利用WebView为HTML5提供容器，业务逻辑使用H5技术实现
