# N版本程序设计

## 概述

N版本程序设计是一种**静态故障屏蔽技术**，采用**前向恢复策略**。其核心思想是用n个具有相同功能的程序同时执行一项计算，结果通过多数表决来选择。

## 核心设计原则

N版本程序设计的关键要求是：**n个版本的程序必须由不同的人（小组）独立设计**，使用不同的方法、不同的设计语言、不同的开发环境和工具来实现。这一要求的目的是减少n个版本程序在表决点上相关错误的概率。

## 特殊开发阶段

与通常软件开发过程不同，N版本程序设计增加了三个新阶段：

1. **相异成分规范评审**：每个版本工作组收到相同的需求规格说明书(SRS)，工作组之间不允许任何形式交流，问题通过问题单形式与项目管理人员交换。

2. **相异性确认**：在相异成分详细设计后进行，目的是对相异性进行评估。

3. **背对背测试**：使用同样的测试数据对N版本程序进行测试，将n个版本程序的运行结果进行比对。

## 工作流程

```
组1 → 版本1 → ┐
组2 → 版本2 → ┼→ 表决器 → 输出正确结果
...            ┤
组n → 版本n → ┘
```
