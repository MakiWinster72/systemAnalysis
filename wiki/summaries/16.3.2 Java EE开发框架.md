## Java EE开发框架

本文介绍了基于Java EE的企业级Web应用开发框架，重点讲解了SSH框架组合（Spring、Struts、Hibernate）的轻量级架构。

### 核心概念

**框架（Framework）**：一组组件的综合，为一类相关应用提供可重用的框架结构，支持细节设计和代码重用。

**SSH框架组合**：
- **Struts框架**：负责MVC模式中的Controller层，处理用户请求分发和流程控制
- **Spring框架**：提供业务逻辑服务层（Service）和依赖注入（DI）功能，管理应用组件
- **Hibernate框架**：负责数据持久化层（DAO），实现对象-关系映射（ORM）

### 轻量级架构

典型的SSH轻量级架构层次：
1. **视图层**：浏览器/JSP页面
2. **控制层**：Struts Controller（ActionServlet）
3. **业务层**：Spring Service
4. **持久层**：Hibernate DAO
5. **数据层**：数据库

配置通过Struts-config.xml、ApplicationContext-Service.xml、ApplicationContext-Hibernate.xml完成。

### 框架优势

- 降低系统开发难度
- 提高Web应用开发效率
- 增强系统的[[可扩展性]]、可维护性和灵活性
- 实现典型的MVC架构分离

### 相关框架

常用的Java EE框架还包括[[WebWork]]等其他选择，各框架相互协作，共同支持企业级Web应用的快速开发。
