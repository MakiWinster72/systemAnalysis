# 5.7.2 数据挖掘常用技术与方法

## 数据挖掘定义

数据挖掘是从大量、不完全、有噪声、模糊、随机的实际应用数据中，提取隐含的、事先不知道的、但又是潜在有用的信息和知识的过程。

## 数据挖掘流程

数据挖掘是一个完整的过程，包括以下六个阶段：

1. **问题定义**：熟悉背景知识，明确用户需求
2. **建立数据挖掘库**：收集要挖掘的数据到专门数据库中
3. **分析数据**：从数据集中找出规律和趋势，发现因素之间的相关性
4. **调整数据**：对数据进行增删和组合，生成有效描述的新变量
5. **模型化**：运用神经网络、决策树、数理统计等方法建立模型（核心环节）
6. **评价和解释**：评估模型的有效性和实用性

## 数据挖掘常用技术

| 技术 | 说明 |
|------|------|
| [[决策树方法]] | 利用信息论中的互信息（信息增益）寻找最大信息量属性 |
| [[分类方法]] | 将数据按含义划分成组，用于自动发现类 |
| [[粗糙集方法]] | 通过上近似和下近似概念表示不精确概念 |
| [[神经网络]] | 模拟人脑神经元结构，由输入层、中间层、输出层组成 |
| [[关联规则]] | 找出重复出现概率很高的模式 |
| [[概念树方法]] | 对属性按归类方式进行抽象建立层次结构 |
| [[遗传算法]] | 模拟生物进化过程，由繁殖、交叉、变异三个算子组成 |
| [[依赖性分析]] | 在数据条目之间抽取依赖关系 |
| 公式发现 | 对数据项进行数学运算求得数学公式 |
| [[统计分析方法]] | 采用回归分析、相关分析、主成分分析等 |
| [[模糊论方法]] | 利用模糊集合理论进行模糊评判和决策 |
| 可视化分析 | 将多维数据变成多种图形进行剖析 |

## 数据挖掘分析方法

从功能上分为六种分析方法：

1. **[[关联分析]]**：发现不同事件之间的关联性，需要计算最小置信度和最小支持度
2. **[[序列分析]]**：发现一定时间间隔内接连发生的事件
3. **[[分类分析]]**：通过样本特点得到分类规则，主要方法包括贝叶斯方法、神经网络、决策树
4. **[[聚类分析]]**：将无类别样本聚集成不同组，是分类分析的逆过程
5. **[[预测方法]]**：估算连续类型变量的取值，常用回归分析技术
6. **[[时间序列分析]]**：预测未来发展趋势或发现周期性规律

## 数据挖掘技术应用

### [[空间数据挖掘]] (SDM)
从空间数据库中抽取隐含的知识和空间关系，结合GIS、遥感、GPS等技术。空间属性包括空间位置、距离、拓扑关系等。

### [[多媒体数据挖掘]] (MDM)
通过综合分析视听特性和语义发现模式。需解决非结构化数据转化和高维特征向量挖掘问题。

### [[文本数据挖掘]] (TDM)
从文本数据中抽取有价值的信息和知识。分为基于单文档和基于文档集的数据挖掘，应用于客户关系管理、互联网搜索等领域。

---

**关键特征**：数据挖掘是一个多种专家合作、高投入的过程，需要反复进行以不断趋近事物的本质。在实际应用中，各种分析方法经常被综合运用。
