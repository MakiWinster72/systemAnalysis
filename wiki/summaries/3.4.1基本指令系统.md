## 基本指令系统

### 概述

指令系统（指令集）是计算机软件与硬件之间的关键分界面，所有可在机器上直接运行的目标程序都由若干条机器指令组成。指令系统设计由软件和硬件设计人员共同完成，是计算机系统设计中非常关键的环节。

### 硬件与软件实现的权衡

计算机系统任务可分解为若干基本功能，其中极少数必须用硬件指令实现，大多数功能既可用硬件也可用软件（微程序）实现。权衡因素包括：

- **速度**：硬件实现快，软件实现慢
- **价格**：硬件实现成本高，软件实现成本低
- **灵活性**：硬件实现灵活性差，软件实现灵活性好

### 指令系统设计要求

| 要求      | 说明                                       |
| ------- | ---------------------------------------- |
| **完整性** | 作为通用计算机应具备的基本指令种类                        |
| **规整性** | 包括对称性（通用寄存器同等对待）和均匀性（不同数据类型、字长等指令设置同等对待） |
| **高效率** | 指令执行速度快、使用频率高；复杂指令可采用微程序实现               |
| **兼容性** | 计算机系统的生命力所在，保障系统软件和应用软件的集成               |

### 基本指令分类

通用计算机系统的基本指令分为五大类：

1. **数据传送类指令** — [[数据传送]]操作
2. **运算类指令** — 算术运算和逻辑运算
3. **程序控制类指令** — 控制程序执行流程
4. **I/O指令** — 输入输出操作
5. **处理机控制和调试指令** — 处理机状态控制与调试
