# TCP/IP 协议簇总结

## 概述

TCP/IP 协议簇是美国国防部高级研究计划署为建立 ARPANET 开发的一组网络通信协议，是互联网的基础协议标准。其名称来源于两个最核心的协议：传输控制协议（TCP）和网际协议（IP）。

## 四层模型

TCP/IP 协议采用四层结构，由下至上依次为：

- **网络接口层**：负责接收和发送 IP 数据报，与传输媒介直接交互
- **网际层**：构造 IP 数据报，填入地址信息并选择发送路径
- **传输层**：对用户信息进行分段处理，保证可靠传输
- **应用层**：与用户直接交互，如电子邮件、文件传输等服务

这四层模型与 [[OSI七层模型]] 存在对应关系，但更加简化。

## 核心协议

### IP 协议

网际协议（IP）是 TCP/IP 的核心，负责将数据传输到目标地址。IP 数据报由固定 20 字节的基本首部和 0~40 字节的可变任选项组成，包含版本号、服务类型、标识符、生存期、源地址、目的地址等字段。目前主要使用 IPv4，正在逐步向 [[IPv6]] 过渡。

### ICMP 协议

网际控制消息协议（ICMP）用于传送通信问题消息，如数据报无法到达目标、路由器缓存不足等。ICMP 报文封装在 IP 数据报中传送，共有 11 种类型。

### TCP 协议

传输控制协议（TCP）是[[面向连接]]的可靠传输协议。TCP 段头包含源端口、目标端口、发送顺序号、接收顺序号、窗口、校验和等字段，以及 URG、ACK、PSH、RST、SYN、FIN 等六个标志位。TCP 采用[[三次握手]]过程建立连接，并使用[[滑动窗口协议]]进行流量控制。TCP 头和 IP 头共占 40 字节开销。

### UDP 协议

用户数据报协议（UDP）是[[无连接]]的传输协议，开销较小，适用于网络管理（如 SNMP）等对可靠性要求不高的场景。UDP 在 IP 协议基础上增加了端口寻址功能。

### ARP 与 RARP

地址解析协议（ARP）和反向地址解析协议（RARP）是网际层的重要协议：
- ARP：将 [[IP 地址]]转换为物理地址
- RARP：将物理地址转换为 IP 地址

## 分组交换技术

TCP/IP 采用[[分组交换]]技术，将信息分成不超过一定大小的数据包传送。其优点包括避免单用户长时间占用线路，以及传输出错时只需重传出错的数据包。

## 协议间关系


TCP/IP 协议簇允许同层协议实体互相调用完成复杂控制功能，也允许上层直接调用不相邻的下层过程。各层主要协议包括：应用层的 FTP、Telnet、SMTP、SNMP、NFS；传输层的 TCP、UDP；网际层的 IP、ICMP、ARP、RARP；网络接口层的 Ethernet、FDDI、Token-Ring、PPP/SLIP 等。
