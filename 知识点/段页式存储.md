# 段页式存储

## 概述

段页式存储管理是将**分段**和**分页**两种存储管理技术相结合的虚拟存储管理方案。它既保留了分段管理中程序的逻辑完整性，又兼有分页管理在内存分配上的灵活性和高效性。

## 核心内容

### 基本原理

1. **先将主存划分成大小相等的存储块（页框）**
2. **将用户程序按逻辑结构划分成若干段**，每个段有独立的段号
3. **再将每个段划分成若干页**，页的大小与主存页框大小一致
4. **内存以页框为单位离散分配**，一个段的各页可以存放在不连续的页框中

### 地址结构

段页式存储的**逻辑地址**由三部分组成：

```
| 段号(s) | 页号(p) | 页内偏移(d) |
```

### 地址变换过程

1. 从段表寄存器中获取**段表**的起始地址
2. 用段号 $s$ 查询段表，获取该段的**页表**起始地址
3. 用页号 $p$ 查询页表，获取**物理页框号**
4. 物理页框号 + 页内偏移 $d$ = **物理地址**

### 地址变换机构

每个进程有一个段表，每个段有一个页表。因此段页式系统需要**两级查表**：先查段表获得页表地址，再查页表获得物理页框号。

### 请求段页式系统

在段页式存储的基础上，增加了**请求调页**和**页面置换**功能，形成**段页式虚拟存储系统**。当访问的页面不在内存时，产生缺页中断，由操作系统将所需页面调入内存。

### 与其他管理方式的对比

| 管理方式 | 优点 | 缺点 |
|---------|------|------|
| 分区管理 | 简单，开销小 | 存在碎片，利用率低 |
| 分页管理 | 无外部碎片，利用率高 | 程序逻辑不完整 |
| 分段管理 | 符合程序逻辑结构 | 存在外部碎片 |
| **段页式** | 兼具分页和分段优点 | 两次查表，硬件开销较大 |
