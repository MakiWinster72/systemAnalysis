# 应用集成

## 概述

企业应用集成（Enterprise Application Integration, EAI）是将多个企业信息系统连接起来实现无缝集成的技术。它旨在消除因缺乏统一规划而形成的**信息孤岛**，解决数据一致性无法保证、信息无法共享反馈、重复采集输入等问题。

## 核心内容

### 传统EAI的四个集成层次

| 层次                | 定位        | 实现方式                | 特点              |
| ----------------- | --------- | ------------------- | --------------- |
| **表示集成（界面集成）**    | 最浅层次（黑盒）  | 屏幕截取和输入模拟           | 无需了解内部结构；但有性能瓶颈 |
| **数据集成**          | 白盒层次      | 批量文件传输、ODBC、中间件     | 需了解数据结构；统一数据访问  |
| **控制集成（功能/应用集成）** | 业务逻辑层（黑盒） | RPC、RMI、消息中间件、分布式对象 | 通过API实现；灵活但复杂度高 |
| **业务流程集成**        | 最深层次      | BPM、工作流引擎、ESB       | 跨越多个应用和组织的端到端流程 |

### 事件驱动的EAI架构

事件驱动架构（EDA）的核心特点：

- **异步**：消息发出后无需关心响应，系统间无需维持活的链路
- **发布/订阅**：支持多对多交互，事件可发送给多个订阅者
- **解耦**：发布者与订阅者互不知晓对方存在

**五层框架结构**：
1. 企业服务总线（ESB）
2. 应用服务层（需集成的应用和数据库）
3. 总线接入层（适配器服务）
4. 核心服务层（消息分发、队列、数据转换/映射）
5. 业务支持层（流程编排、用户交互服务）

### 集成的关键技术

- **企业服务总线（ESB）**：面向服务体系的基础架构
- **消息中间件**：支持异步可靠消息传递
- **适配器/连接器**：连接异构系统的桥梁
- **数据转换引擎**：处理不同数据格式的映射和转换
