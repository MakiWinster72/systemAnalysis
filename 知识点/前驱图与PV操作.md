# 前驱图与PV操作

## 概述

前驱图与PV操作是操作系统中进程管理的核心概念。前驱图用于描述程序间执行顺序的约束关系，而PV操作则是实现进程**同步与互斥**的经典机制，由荷兰学者Dijkstra于1965年提出。

## 核心内容

### 前驱图

**前驱图**是一个有向无循环图（DAG），用于描述程序段或进程之间的执行顺序约束：

- **结点**：代表程序段的操作（或一个进程）
- **有向边** $P_i \to P_j$：表示 $P_i$ 必须执行完毕后 $P_j$ 才能开始
- 程序顺序执行的三大特征：**顺序性**、**封闭性**和**可再现性**

### 进程的状态模型

**三态模型**：
- **运行态（Running）**：正在处理机上执行，单处理机系统只有一个
- **就绪态（Ready）**：获得除处理机外的所有资源，等待调度
- **阻塞态（Blocked）**：等待某事件发生而暂停执行

**五态模型**：在三态基础上增加了新建态（New）和终止态（Terminated）

### 信号量与PV操作

**信号量（Semaphore**是一个整数变量，分为两种：
- **公用信号量**：实现互斥，初值为 1 或可用资源数
- **私用信号量**：实现同步，初值为 0 或正整数

**P操作**（申请资源，Proberen）：
```
S := S - 1
若 S < 0，则进程阻塞并插入阻塞队列
```

**V操作**（释放资源，Verhogen）：
```
S := S + 1
若 S ≤ 0，则从阻塞队列中唤醒一个进程
```

### 经典应用场景

- **生产者-消费者问题**：用PV操作协调生产者和消费者的同步
- **读者-写者问题**：控制对共享资源的读写访问
- **哲学家进餐问题**：解决多进程的资源竞争
- **进程互斥**：保证临界区资源的独占访问

### 高级通信机制

相比于PV操作的低级通信，高级通信方式包括：
- **共享存储模式**：进程间共享数据结构或存储区
- **消息传递模式**：以消息为单位进行通信（Send/Receive）
- **管道通信**：通过共享文件（pipe）实现进程间字符流通信

## 在系统分析中的应用

- **并发系统设计**：用前驱图分析系统的并发执行路径
- **同步控制设计**：用信号量机制设计多线程/多进程的同步方案
- **死锁分析**：PV操作不当使用可能导致死锁，需结合银行家算法预防
