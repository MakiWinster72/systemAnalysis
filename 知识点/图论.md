# 图论

## 概述

图论是数学的一个分支，研究由顶点和边组成的图结构的性质与算法。在系统分析中，图论被广泛应用于网络设计、项目调度、资源分配和流程优化等场景。

## 核心内容

### 最小生成树

最小生成树是带权连通无向图中权值和最小的生成树，包含图中所有顶点。三种经典算法：

| 算法                 | 核心思想                      | 时间复杂度         | 适用场景      |
| ------------------ | ------------------------- | ------------- | --------- |
| **普里姆(Prim)**      | 从某顶点开始，每次添加连接已选集和未选集的最小权边 | $O(n^2)$      | 稠密图       |
| **克鲁斯卡尔(Kruskal)** | 按边权递增依次选择n-1条安全边          | $O(e \log e)$ | 稀疏图       |
| **博鲁夫卡(Boruvka)**  | 每个连通分量找最小连出边，重复至全连通       | $O(E \log V)$ | 可并行化的大规模图 |

工程应用：网络布线设计、管道铺设优化，实现时间最少、费用最省的目标。

### 最短路径

求解两个顶点间权值总和最小的路径。六种经典算法：

| 算法                 | 适用场景        | 时间复杂度                        |
| ------------------ | ----------- | ---------------------------- |
| **Dijkstra**       | 无负权边单源最短路径  | $O(V^2)$ 或 $O(E\log V)$（堆优化） |
| **Floyd-Warshall** | 所有节点对最短路径   | $O(V^3)$                     |
| **Bellman-Ford**   | 含负权边，可检测负环  | $O(nm)$                      |
| **A\***            | 有启发信息的目标搜索  | $O(b^d)$                     |
| **Johnson**        | 全源最短路径（含负边） | $O(VE\log V)$                |
| **SPFA**           | 含负权边单源最短路径  | 最坏 $O(VE)$                   |

## 在系统分析中的应用

- **网络拓扑优化**：使用最小生成树设计通信网络和布线方案
- **路由选择**：Dijkstra算法用于网络路由协议（如OSPF）
- **项目调度**：用最长路径（关键路径）分析项目工期
- **物流路径**：最短路径算法优化配送路线
- **社交网络分析**：图论算法分析用户关系网络
