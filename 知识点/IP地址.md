# IP地址

## 概述

IP地址是计算机网络中用于唯一标识网络节点的关键逻辑地址。Internet依靠TCP/IP协议簇在全球范围内实现不同硬件、不同操作系统、不同网络系统的互连，每个节点依靠唯一的IP地址互相区分和相互联系。

## 核心内容

### IPv4地址结构

IPv4地址为**32位**二进制数，通常表示为4个十进制字节（如 `192.168.200.128`）。

每个IP地址由两部分组成：
- **网络号**：唯一标识一个网络
- **主机号**：确定网络上的某台主机

### IPv4地址分类

| 类别  | 最高位  | 网络号位数 | 主机号位数 | 地址范围                      | 用途   |
| --- | ---- | ----- | ----- | ------------------------- | ---- |
| A类  | 0    | 8位    | 24位   | 1.0.0.0~126.255.255.255   | 大型网络 |
| B类  | 10   | 16位   | 16位   | 128.0.0.0~191.255.255.255 | 中型网络 |
| C类  | 110  | 24位   | 8位    | 192.0.0.0~223.255.255.255 | 小型网络 |
| D类  | 1110 | -     | -     | 224.0.0.0~239.255.255.255 | 组播   |
| E类  | 1111 | -     | -     | 240.0.0.0~255.255.255.255 | 保留   |

### 私有地址（保留地址）

- A类私网：`10.0.0.0 ~ 10.255.255.255`
- B类私网：`172.16.0.0 ~ 172.31.255.255`
- C类私网：`192.168.0.0 ~ 192.168.255.255`

### 子网划分

将IP地址划分为**网络号 + 子网号 + 主机号**三部分：

- **子网掩码**：网络和子网标识位全为1，主机位全为0（如 `255.255.240.0`）
- **判断方法**：两个IP分别与子网掩码做**逻辑与运算**，结果相等则属于同一子网

### CIDR（无分类域间路由）

- 消除A/B/C类地址的分类限制
- 记法：在IP地址后加 `/<前缀位数>`（如 `128.2.3.4/20`）
- **路由汇聚**：利用CIDR地址块查找目的网络，显著缩小路由表尺寸

### IPv6

- 地址长度从32位扩展到**128位**
- 地址空间极大，几乎无限
- 更小的路由表、增强的组播支持、原生自动配置、内置加密和校验
