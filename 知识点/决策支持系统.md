# 决策支持系统

## 概述

决策支持系统（Decision Support System, DSS）是辅助决策者通过**数据、模型和知识**，以人机交互方式进行半结构化或非结构化决策的计算机应用系统。它为决策者提供分析问题、建立模型、模拟决策过程和方案评估的环境。

## 核心内容

### DSS的基本特征

- 面向**中高层管理人员**的决策问题
- 支持**半结构化和非结构化**决策
- 强调**辅助**决策而非替代决策
- 以**数据、模型和知识**为三大支柱
- 强调**人机交互**的灵活性

### 体系结构（四库结构）

| 子系统 | 功能 |
|--------|------|
| **数据库子系统** | 存储、管理、提供与维护用于决策支持的数据 |
| **模型库子系统** | 管理决策模型（预测、规划、优化等） |
| **方法库子系统** | 存储常用算法和方法 |
| **人机交互子系统** | 提供灵活友好的用户界面 |

### DSS与相关系统的关系

| 系统 | 与DSS的关系 |
|------|------------|
| **数据仓库** | 为DSS提供高质量、集成的数据基础 |
| **OLAP** | 为DSS提供多维数据分析和快速查询 |
| **数据挖掘** | 为DSS提供自动发现模式和知识的能力 |
| **商业智能（BI）** | BI是DSS的现代发展，融合了上述技术 |

### 决策过程的四个阶段

1. **情报活动**：识别问题、收集信息
2. **设计活动**：设计可能的解决方案
3. **抉择活动**：评估和选择最佳方案
4. **实施活动**：执行决策并跟踪反馈

### 决策方法

**定性方法**：德尔菲法、头脑风暴法、名义群体法

**定量方法**：
- 线性规划（资源优化）
- 决策树分析（不确定决策）
- 成本效益分析
- 蒙特卡罗模拟（风险评估）
