# Pert图

## 概述

PERT（Program Evaluation and Review Technique，计划评审技术）是一种用于项目进度管理的**网络图**工具，用于分析和表示项目任务之间的依赖关系，识别关键路径，从而确定项目的最短完成时间。PERT特别适用于活动历时不确定的大型复杂项目。

## 核心内容

### PERT图的基本要素

- **事件（节点）**：代表一个活动的开始或结束，是一个时间点
- **活动（箭线）**：代表需要消耗时间和资源的工作
- **关键路径**：从起点到终点的最长路径，决定项目最短工期

### PERT的三点估算法

每个活动的历时用三个值估计：

- **乐观时间（a）**：最理想条件下完成活动的时间
- **最可能时间（m）**：正常情况下完成活动的时间
- **悲观时间（b）**：最不利条件下完成活动的时间

**期望时间**的计算公式：
$$t_e = \frac{a + 4m + b}{6}$$

**方差**（不确定性度量）：
$$\sigma^2 = \left(\frac{b - a}{6}\right)^2$$

### 前导图法（PDM）

用节点表示活动，箭线表示依赖关系。每个节点记录四个时间参数：

| 参数 | 含义 |
|------|------|
| ES（最早开始时间） | 活动可开始的最早时间 |
| EF（最早结束时间） | 活动可结束的最早时间（EF = ES + 历时） |
| LS（最迟开始时间） | 活动必须开始的最迟时间 |
| LF（最迟结束时间） | 活动必须结束的最迟时间（LF = LS + 历时） |

### 关键路径法（CPM）

- 计算每个活动的总时差（Float）：$TF = LS - ES = LF - EF$
- 总时差 = 0 的活动构成**关键路径**
- 关键路径上的任何延迟都会导致项目工期延长

### 四种依赖关系

1. **FS（完成-开始）**：前序完成后续才能开始（最常用）
2. **FF（完成-完成）**：前序完成后后续才能完成
3. **SS（开始-开始）**：前序开始后后续才能开始
4. **SF（开始-完成）**：前序开始后后续才能完成（极少使用）
