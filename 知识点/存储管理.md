# 存储管理

## 概述

存储管理是操作系统和计算机体系结构的核心功能之一，负责对存储器资源进行分配、保护和扩充。存储器是计算机的记忆装置，通过**分层存储结构**实现容量、速度和成本的最优平衡。

## 核心内容

### 存储器的层次结构

由高速到低速、由小容量到大容量：

```
寄存器 → Cache（高速缓存）→ 主存（内存）→ 辅存（外存）
```

层次结构的理论基础是**程序局部性原理**：时间局部性（刚访问的数据很可能再次访问）和空间局部性（刚访问数据附近的数据很可能被访问）。

### 高速缓冲存储器（Cache）

- **作用**：在CPU和主存之间提供高速数据缓冲
- **地址映射**：直接映射、全相联映射、组相联映射
- **替换算法**：随机替换、FIFO、LRU（近期最少使用）
- **写策略**：写直达（Write Through）、写回（Write Back）

### 辅助存储器

| 类型        | 特点                            |
| --------- | ----------------------------- |
| 磁带        | 顺序存取，容量大，成本低，适合归档备份           |
| HDD（机械硬盘） | 随机存取，容量大，有机械延迟                |
| SSD（固态硬盘） | 速度快，无机械部件，功耗低                 |
| RAID磁盘阵列  | 通过冗余提高可靠性和性能（RAID0/1/5/6/10等） |

### 虚拟存储技术

虚拟存储将多个存储介质模块通过集中管理形成统一管理的存储池（Storage Pool），核心是实现**物理存储实体与存储逻辑表示的分离**。

**分类方式**：
- 按拓扑：对称式（控制设备集成在网络路径中）vs 非对称式（独立于数据路径）
- 按原理：数据块虚拟（解决传输冲突和延时）vs 虚拟文件系统（解决安全机制）

**实现方式**：
- 主机级虚拟化（卷管理软件实现，成本低）
- 存储设备级虚拟化（存储控制器实现）
- 网络级虚拟化（通过SAN专用装置实现，开放性最好）

### 存储器特点

- **集中管理**：统一管理，新增存储无需客户端操作
- **负载平衡**：数据访问带宽合理分配到各存储模块
- **灵活兼容**：可管理不同类型存储设备
