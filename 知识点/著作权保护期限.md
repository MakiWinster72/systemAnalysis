# 著作权保护期限

## 概述

著作权（版权）的保护期限是指著作权中的各项权利受法律保护的持续时长。不同权利主体、不同权利类型以及不同类型的作品有不同的保护期限。保护期满后，作品进入**公共领域**，任何人都可以自由使用。

## 核心内容

### 公民（自然人）作品的保护期限

| 权利类型 | 保护期限 |
|---------|---------|
| **署名权、修改权、保护作品完整权** | **永久保护**，不受时间限制 |
| **发表权、财产权**（复制、发行、出租、展览权等） | 作者**终生** + 作者死亡后 **50年**（至第50年的12月31日） |

合作作品：死亡后50年从**最后死亡的作者**死亡之日起算。

### 法人或其他组织作品的保护期限

| 权利类型 | 保护期限 |
|---------|---------|
| 财产权 | 作品**首次发表**后 **50年**（至第50年的12月31日） |
| 50年内未发表 | 自创作完成后50年，不再保护 |

### 特殊类型作品的保护期限

| 作品类型 | 保护期限 |
|---------|---------|
| **电影作品和以类似摄制电影方法创作的作品** | 首次发表后50年 |
| **摄影作品** | 首次发表后50年 |
| **计算机软件** | 自然人：终生+50年；法人：首次发表后50年 |
| **匿名/假名作品** | 首次发表后50年（身份确定后按一般规定） |
| **图书/期刊版式设计** | 首次出版后**10年** |

### 保护期限的计算规则

- "创作完成之日"：作品完成的时间点
- "首次发表"：作品首次公之于众的时间
- 保护期截止于第50/10年的**12月31日**
- 作者死亡后50年内未发表的作品，不再受著作权法保护

### 不受著作权法保护的对象

- 法律、法规，国家机关的决议、决定、命令
- 时事新闻
- 历法、通用数表、通用表格和公式
- 思想、过程、操作方法（著作权只保护表达，不保护思想）
