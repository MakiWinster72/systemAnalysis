# 电子商务

## 概述

电子商务（Electronic Commerce, EC）是利用计算机技术、网络技术和远程通信技术，实现整个商务过程的电子化、数字化和网络化。完整的电子商务涉及买家、卖家、银行、政府机构、认证机构、配送中心等多方参与。

## 核心内容

### 按交易对象分类的主要模式

| 模式 | 全称 | 说明 |
|------|------|------|
| **B2C** | 企业对消费者 | 借助Internet开展在线销售，如京东、天猫 |
| **B2B** | 企业对企业 | 企业间的网上采购、付款等商务联系 |
| **C2C** | 消费者对消费者 | 个人间的在线交易，如拍卖平台 |
| **B2G** | 企业对政府 | 政府采购企业产品和服务 |
| **O2O** | 线上到线下 | 线上营销带动线下消费 |

### 其他分类方式

- **按商业互动运行方式**：完全电子商务 vs 非完全电子商务
- **按交易范围**：区域化电子商务、国内远程电子商务、全球电子商务

### 五大核心技术

| 技术类别 | 说明 |
|---------|------|
| 网络数据通信技术 | 互联网和数据通信是电子商务的基础网络基础设施 |
| 电子数据交换（EDI）技术 | 企业间标准化的电子格式数据交换 |
| 安全技术 | 数据加密、数字签名、安全认证（SSL/HTTPS） |
| 电子支付技术 | 网上银行、第三方支付、数字货币 |
| 数据库技术 | 存储和管理产品、订单、用户等核心数据 |

### 电子商务标准体系

我国电子商务标准体系框架涵盖：
- 电子商务基础标准
- 电子商务业务标准
- 电子商务支撑体系标准
- 电子商务监督管理标准
