# 索引文件

## 概述

索引文件是计算机文件组织的一种物理结构，通过建立**索引表**来记录文件数据块的物理存储位置。与连续结构和链接结构不同，索引结构将文件块的地址集中存储在索引表中，访问时通过索引表快速定位。

## 核心内容

### 文件物理结构的三种基本类型

| 结构类型 | 特点 | 优缺点 |
|---------|------|--------|
| **连续结构** | 文件占用连续的物理块 | 访问快，但扩展困难、有碎片 |
| **链接结构** | 物理块通过指针连接 | 无碎片，但随机访问慢 |
| **索引结构** | 通过索引表访问文件块 | 支持随机访问，但索引表占用空间 |

### 索引结构的工作原理

1. 每个文件有一个**索引表**（索引结点/Inode）
2. 索引表记录文件中各逻辑块对应的**物理块号**
3. 访问文件时，从索引表查找目标块的物理地址
4. 根据物理地址直接存取文件块

### 多重索引方式（UNIX采用）

为解决大文件索引表过大的问题，UNIX采用三级索引结构：

- **直接寻址**：前若干指针直接指向数据块（适合小文件）
- **一级间接寻址**：指针指向一个索引块，索引块指向数据块
- **二级间接寻址**：指针指向的索引块再指向索引块，再指向数据块
- **三级间接寻址**：三级指针链，支持超大型文件

### 索引文件的优缺点

**优点**：
- 支持随机访问和顺序访问
- 增删记录方便（只需修改索引表）
- 无外部碎片

**缺点**：
- 索引表占用额外存储空间
- 大型文件的索引表查找开销较大
- 索引表也需要维护和管理

### 与索引相关的数据库概念

在数据库系统中，**索引**是提高查询效率的重要手段：
- B+树索引：适合范围查询和排序
- 哈希索引：适合等值查询
- 位图索引：适合低基数列
