# 位示图

## 概述

位示图（Bitmap）是操作系统中管理**磁盘存储空间**的一种经典方法。它使用一个二进制位（0或1）来表示磁盘上每个物理块的使用状态，从而实现对空闲空间的快速分配和回收。

## 核心内容

### 基本原理

- 磁盘被划分为固定大小的**物理块**
- 每位对应一个物理块：**0 表示空闲，1 表示已占用**
- 所有位按顺序排列成一个位图，通常存放在磁盘的固定位置

### 字位映射关系

假设字长为 $n$ 位，则第 $i$ 个字、第 $j$ 位对应的物理块号为：

$$\text{块号} = i \times n + j$$

反之，物理块号 $b$ 对应：

- 字号 $i = \lfloor b / n \rfloor$
- 位号 $j = b \bmod n$

### 分配与回收操作

**分配物理块**：
1. 在位示图中查找值为 0 的位
2. 将该位置为 1
3. 计算对应的物理块号
4. 返回物理块号

**回收物理块**：
1. 根据物理块号计算字号和位号
2. 将对应位清 0

### 优缺点

| 优点 | 缺点 |
|------|------|
| 实现简单，查找快速 | 位示图本身占用存储空间 |
| 支持连续分配和离散分配 | 对于大磁盘，位图可能较大 |
| 适合各种文件物理结构 | 需要常驻内存 |

### 与其他存储管理方法的对比

| 方法 | 原理 | 适用场景 |
|------|------|---------|
| **位示图** | 每位对应一块，0/1标记空闲 | 各种物理结构，通用性强 |
| 空闲区表 | 记录连续未分配区域 | 连续文件结构 |
| 空闲块链 | 空闲块通过指针构成链表 | 节省空间 |
| 成组链接法 | UNIX采用，每100块为一组 | 大型文件系统 |
