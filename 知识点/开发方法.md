# 开发方法

## 概述

信息系统开发方法是指导信息系统建设的系统化方法论。信息系统是复杂的人机交互系统，涵盖计算机、通信和网络等多种工程技术，需要管理理论支持。选择正确的开发方法对项目成功至关重要。

## 核心内容

### 三种主要开发方法

| 方法         | 核心思想            | 阶段划分               | 特点          |
| ---------- | --------------- | ------------------ | ----------- |
| **结构化方法**  | 自顶向下、逐步求精、模块化设计 | SA → SD → SP       | 经典、规范、文档驱动  |
| **面向对象方法** | 抽象、封装、继承、多态     | OOA → OOD → OOP    | 接近人类思维、复用性强 |
| **面向服务方法** | 接口定义与实现解耦       | 服务识别 → 服务设计 → 服务编排 | 灵活、松耦合、可组合  |

### 结构化方法（生命周期法）

- **结构化分析（SA）**：使用数据流图（DFD）、数据字典等工具分析需求
- **结构化设计（SD）**：使用模块结构图进行系统架构设计
- **结构化程序设计（SP）**：采用顺序、选择、循环三种基本结构编写程序

**生命周期阶段**：系统规划 → 系统分析 → 系统设计 → 系统实施 → 系统维护

### 面向对象方法

- **面向对象分析（OOA）**：识别问题域中的对象、类及其关系，构造对象模型
- **面向对象设计（OOD）**：设计系统的对象结构、交互行为和持久化方案
- **面向对象程序设计（OOP）**：使用面向对象语言实现系统

核心概念：抽象、封装、继承、多态

### 面向服务方法（SO）

从技术演进角度来看：
$$\text{面向对象} \to \text{基于构件} \to \text{面向服务}$$

面向服务方法使信息系统能够快速响应需求与环境变化，提高可复用性、资源共享和系统互操作性。

### 方法选择考虑因素

- 项目规模和复杂度
- 需求的明确程度
- 团队技能和经验
- 时间进度要求
- 组织文化和流程成熟度
