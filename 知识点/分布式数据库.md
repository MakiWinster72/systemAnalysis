# 分布式数据库

## 概述

分布式数据库是由一组数据组成的，这组数据分布在计算机网络的不同计算机上。网络中的每个节点具有**独立处理能力（场地自治）**，可以执行局部应用，同时也能通过网络通信子系统执行全局应用。

## 核心内容

### 四大特点

1. **数据独立性**：除逻辑和物理独立性外，还具有**数据分布独立性（分布透明性）**
2. **集中与自治结合的控制结构**：局部DBMS独立管理 + 集中控制协调全局事务
3. **适当增加数据冗余度**：在不同场地存储同一数据的多副本，提高可靠性和可用性
4. **全局的一致性、可串行性和可恢复性**

### 三层模式体系结构

```
全局外模式 → 全局概念模式 → 分片模式 → 分布模式 → 局部概念模式 → 局部内模式 → 局部数据库
```

- **全局层**（新增）：全局外模式、全局概念模式、全局DBMS
- **映射层**：分片模式（映射1）、分布模式（映射2-3）
- **局部层**：局部DBMS及局部数据库（与集中式一致）

### 数据分片技术

数据分片是将全局关系的逻辑结构分解为片段，是分布式数据库的核心技术：

| 分片方式 | 定义 |
|---------|------|
| **水平分片** | 按元组（行）进行划分 |
| **垂直分片** | 按属性（列）进行分裂，通过连接运算重构全局关系 |
| **导出分片** | 根据另一关系的属性值对当前关系分片 |
| **混合分片** | 上述方式的组合 |

### 分布透明性

| 层次 | 含义 |
|------|------|
| 分片透明性 | 用户无需知道数据如何分片（最高级） |
| 位置透明性 | 用户无需知道数据存放在哪个场地 |
| 局部数据模型透明性 | 用户无需知道局部DBMS的数据模型 |

### 与集中式数据库的对比

| 特性    | 集中式    | 分布式        |
| ----- | ------ | ---------- |
| 数据存储  | 单一节点   | 多个节点       |
| 扩展性   | 垂直扩展为主 | 水平扩展       |
| 可靠性   | 单点故障风险 | 副本机制提高可靠性  |
| 通信开销  | 无      | 需网络同步      |
| CAP理论 | 一致性强   | 需在C/A/P间权衡 |
