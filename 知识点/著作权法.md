# 著作权法

## 概述

著作权法（版权法）是保护文学、艺术和科学作品作者著作权及其相关权益的法律规范总和。在中国，主要依据**《中华人民共和国著作权法》**及其实施条例。著作权自动产生于作品创作完成之时，**无需登记或发表**，遵循"自动保护"原则。

## 核心内容

### 著作权的主体（谁拥有著作权）

| 主体 | 说明 |
|------|------|
| **作者（自然人）** | 创作作品的公民，著作权原始所有者 |
| **法人或其他组织** | 在特定条件下视为作者（如由单位主持、代表单位意志创作、单位承担责任的作品） |
| **合作作者** | 两人以上合作创作的作品，著作权由合作者共同享有 |
| **委托作品受托人** | 通过合同约定；无约定则著作权归**受托人** |
| **职务作品作者** | 一般职务作品归作者（单位有优先使用权）；特殊职务作品归单位（作者有署名权） |

### 著作权的内容

**人身权（永不可转让）**：
1. **发表权**：决定作品是否公之于众
2. **署名权**：表明作者身份，在作品上署名
3. **修改权**：修改或授权他人修改作品
4. **保护作品完整权**：保护作品不受歪曲、篡改

**财产权（可许可/转让）**：
1. 复制权、发行权、出租权
2. 展览权、表演权、放映权、广播权
3. 信息网络传播权
4. 摄制权、改编权、翻译权、汇编权

### 软件著作权

《计算机软件保护条例》对软件著作权做了专门规定：

- 软件著作权自**软件开发完成之日**起产生
- 保护对象：计算机程序及其相关文档
- 不保护：开发软件所用的**思想、处理过程、操作方法或数学概念**
- 软件合法复制品所有人享有：安装使用、备份复制、必要修改等权利

### 著作权的限制——合理使用

在特定条件下使用他人作品，**可以不经过许可、不支付报酬**（但须注明作者和作品名称）：

| 情形 | 举例 |
|------|------|
| 个人使用 | 个人学习、研究、欣赏 |
| 引用说明 | 为介绍、评论适当引用 |
| 教学科研 | 课堂教学或科研少量复制 |
| 公务使用 | 国家机关执行公务 |
| 免费表演 | 未收费且未向表演者付酬 |

### 软件反向工程的合法边界

- 合法取得软件复制品的人，为获得软件与其他软件的兼容性，可以对软件进行**反向工程**
- 但不得将反向工程获取的信息用于侵权目的
- 可使用**净室技术**避免版权侵权
