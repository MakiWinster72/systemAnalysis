# TCP/IP协议簇

## 概述

TCP/IP协议簇（Transmission Control Protocol / Internet Protocol Suite）是美国国防部高级研究计划署为建立ARPANET开发的一组网络通信协议，也是现代互联网的基础协议标准。其名称来源于最核心的两个协议：**TCP（传输控制协议）**和**IP（网际协议）**。

## 核心内容

### 四层模型（自下而上）

| 层次        | 功能                    | 主要协议                                 |
| --------- | --------------------- | ------------------------------------ |
| **网络接口层** | 接收和发送IP数据报，与传输媒介直接交互  | Ethernet, FDDI, Token-Ring, PPP/SLIP |
| **网际层**   | 构造IP数据报，填入地址信息并选择发送路径 | IP, ICMP, ARP, RARP                  |
| **传输层**   | 对用户信息进行分段处理，保证可靠传输    | TCP, UDP                             |
| **应用层**   | 与用户直接交互，提供服务          | FTP, Telnet, SMTP, SNMP, HTTP, DNS   |

与七层OSI模型的对应关系：TCP/IP的四层模型更加简化，其应用层对应OSI的应用层+表示层+会话层。

### 核心协议详解

**IP协议（网际层核心）**：
- 负责将数据传输到目标地址
- IP数据报：20字节固定首部 + 0~40字节可变选项
- 本质是无连接、不可靠的传输

**TCP协议（面向连接）**：
- 采用**三次握手**建立连接（SYN → SYN+ACK → ACK）
- 通过**滑动窗口协议**进行流量控制
- 提供可靠的端到端传输服务
- 段头包含源/目标端口、序列号、确认号等关键字段

**UDP协议（无连接）**：
- 开销小、速度快，不保证可靠传输
- 适用于网络管理（SNMP）、音视频流等场景

**ICMP协议**：传递通信中的错误消息和控制信息（如目标不可达、超时等）

**ARP/RARP**：
- ARP：IP地址 → 物理地址（MAC地址）
- RARP：物理地址 → IP地址

### 分组交换技术

TCP/IP采用**分组交换**技术，将信息分成不超过一定大小的数据包传送：
- 避免单用户长时间占用线路
- 传输出错时只需重传出错的数据包，而非整个文件
