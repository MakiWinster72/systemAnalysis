# 侵权判定

## 概述

著作权侵权判定是确定某一行为是否构成对他人著作权的侵犯的法律判断过程。侵权判定通常遵循**接触+实质性相似**原则，即被控侵权人有接触原作品的可能，且被控作品与原作品之间存在实质性的相似。

## 核心内容

### 侵权构成要件

| 要件 | 说明 |
|------|------|
| **侵权行为** | 未经许可使用他人享有著作权的作品 |
| **损害事实** | 对著作权人造成实际或潜在的损害 |
| **因果关系** | 侵权行为与损害结果之间存在因果关联 |
| **主观过错** | 故意或过失（严格责任下可不考虑） |

### 侵权判定的核心原则

#### "接触 + 实质性相似"原则

1. **接触（Access）**：
   - 被控侵权人有机会接触或了解原作品
   - 如原作已公开发表，即推定有接触可能性
   
2. **实质性相似（Substantial Similarity）**：
   - 两者在受保护元素上存在实质性相似
   - 不要求完全相同，只需关键部分相似
   - 排除不受保护的思想、事实、通用元素

#### 思想/表达二分法

- 著作权只保护**表达（Expression）**，不保护**思想（Idea）**
- 两个作品主题相同 ≠ 侵权
- 判断标准：抽象概括法——越抽象越接近思想（不受保护），越具体越接近表达（受保护）

### 软件侵权的特殊判定

| 侵权类型 | 说明 |
|---------|------|
| **代码抄袭** | 源代码或目标代码的完全或实质性复制 |
| **结构相似** | 程序结构、顺序和组织（SSO）实质性相似 |
| **界面抄袭** | 用户界面的外观和感觉（Look and Feel）复制 |
| **非法修改** | 未经许可修改和翻译他人软件 |

### 侵权抗辩事由

| 抗辩理由 | 说明 |
|---------|------|
| **独立创作** | 虽相似但系独立创作（无接触则不构成侵权） |
| **合理使用** | 为个人学习、评论、教学科研等目的使用 |
| **法定许可** | 法律规定的无需许可的使用情形 |
| **已过保护期** | 作品已进入公共领域 |
| **思想而非表达** | 仅借用了不受保护的思想 |
| **必要场景原则** | 特定主题的有限表达方式 |
| **净室开发** | 两组人员隔离，独立重新实现 |

### 侵权救济措施

| 措施 | 说明 |
|------|------|
| **停止侵害** | 责令停止侵权行为 |
| **消除影响** | 公开赔礼道歉、消除不良影响 |
| **赔偿损失** | 实际损失或侵权人违法所得，难以计算的可**法定赔偿**（最高500万元） |
| **行政处罚** | 行政管理部门责令停止侵权、没收违法所得、罚款 |
| **刑事制裁** | 情节严重者追究刑事责任 |

### 逆向工程的合法性边界

- 逆向工程本身**不等于**侵犯知识产权
- 在某些情况下反而**保护**知识产权所有者（如侵权取证）
- 从事逆向工程时使用**净室技术**可有效避免版权问题：一组人员分析产品并编写规格说明，另一组独立人员（未接触原产品）根据规格说明实现
