# 商业智能

## 概述

商业智能（Business Intelligence, BI）是从业务数据中提取有用信息，并据此采取明智行动的技术和应用的集合。它通过**数据仓库、数据抽取、OLAP、数据挖掘**等技术，将企业积累的数据转化为支持决策的信息资产。

## 核心内容

### 商业智能的核心功能

- **数据整合**：从多个业务系统汇聚数据
- **数据分析**：通过OLAP和多维分析发现趋势和规律
- **数据可视化**：以图表和仪表盘直观呈现分析结果
- **决策支持**：为管理者提供及时、准确的信息辅助决策

### 商业智能产品分类

| 类别 | 说明 |
|------|------|
| 数据仓库产品 | 存储和管理企业级数据 |
| 数据抽取产品 | ETL工具，从各业务系统获取数据 |
| OLAP产品 | 多维度在线分析处理 |
| 展示产品 | 数据可视化和报表 |
| 整体解决方案 | 集成以上所有功能的统一平台 |

### BI与知识管理

BI的发展与**知识管理**密切相关。知识分为两类：

| 显性知识 | 隐性知识 |
|---------|---------|
| 规范、系统、有科学基础 | 非正式、难以规范、个人化 |
| 经过编码、格式化、结构化 | 尚未编码、格式化、结构化 |
| 易于存储、共享和传递 | 不易保存和传递 |

**知识管理工具**：
- **知识生成工具**：知识获取、合成和创新（搜索引擎、数据挖掘）
- **知识编码工具**：将知识有效存储并以简明方式呈现
- **知识转移工具**：消除时间差异、空间差异和社会差异的知识传播障碍

### BI与相关技术的关系

```
数据源(ERP/CRM/SCM) → ETL → 数据仓库 → OLAP/数据挖掘 → BI展示 → 决策行动
```
