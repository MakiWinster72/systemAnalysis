# 关系代数

## 概述

关系代数是一种基于集合论的**过程化查询语言**，用对关系的运算来表达查询。它是关系数据库理论的数学基础，也是SQL语言查询优化的理论依据。关系代数共有8种基本运算。

## 核心内容

### 集合运算（要求两个关系有相同的目和属性域）

| 运算 | 符号 | 说明 |
|------|------|------|
| **并（Union）** | $R \cup S$ | 属于R或属于S的所有元组 |
| **差（Difference）** | $R - S$ | 属于R但不属于S的元组 |
| **交（Intersection）** | $R \cap S$ | 同时属于R和S的元组 |
| **笛卡儿积（Cartesian Product）** | $R \times S$ | R的每个元组与S的每个元组拼接（m+n目） |

### 专门的关系运算

| 运算 | 符号 | 说明 |
|------|------|------|
| **投影（Projection）** | $\pi_{A_1,A_2,...,A_n}(R)$ | 从列的角度抽取指定属性，去除重复行 |
| **选择（Selection）** | $\sigma_{F}(R)$ | 从行的角度筛选满足条件F的元组 |

### 连接运算

- **$\theta$ 连接**：$R \bowtie_{A\theta B} S$，从笛卡儿积中选取满足条件的元组
- **等值连接**：$\theta$ 为 "=" 时的连接
- **自然连接**：$R \bowtie S$，特殊的等值连接——比较分量必须是相同属性组，结果去除重复列

### 除运算

$R \div S$：设 R(X,Y) 和 S(Z)，Y与Z属性个数相同。商关系是R在X上投影的子集，该子集与S的笛卡儿积必包含在R中。

**直观理解**：求"对于R中的每个X，是否包含S中所有Y的对应"问题——例如"查询选修了全部课程的学生"。

### 五种基本运算

以下五种运算是**不可再分**的基本操作，其他运算可由它们组合导出：
1. 并（$\cup$）
2. 差（$-$）
3. 笛卡儿积（$\times$）
4. 投影（$\pi$）
5. 选择（$\sigma$）

## 在SQL中的对应关系

| 关系代数 | SQL |
|---------|-----|
| $\sigma$（选择） | WHERE |
| $\pi$（投影） | SELECT 列名 |
| $\times$（笛卡儿积） | FROM 表1, 表2 |
| $\bowtie$（连接） | JOIN ... ON |
| $\cup$（并） | UNION |
