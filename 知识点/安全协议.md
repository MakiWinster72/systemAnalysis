# 安全协议

## 概述

安全协议是在计算机网络中保证数据传输安全性的一系列规范和标准。它们主要保护网络通信中的**机密性、完整性和可用性**，是构建安全网络应用的基石。主要安全协议包括**SSL/TLS、HTTPS、IPSec、PGP**等。

## 核心内容

### SSL/TLS（传输层安全协议）

SSL/TLS是应用最广泛的传输层安全协议，位于TCP和应用层之间。

**SSL的三个子协议**：

| 子协议 | 功能 |
|--------|------|
| **握手协议** | 协商版本、密钥交换算法、加密算法和Hash算法；双向身份验证 |
| **记录协议** | 对应用层数据进行加密、压缩和MAC计算 |
| **警报协议** | 传递SSL出错信息（警告/致命错误） |

**SSL的六个实现阶段**：
1. 接通阶段
2. 密钥交换阶段（RSA / Diffie-Hellman / Fortezza-KEA）
3. 会谈密钥阶段
4. 检验阶段
5. 客户认证阶段（可选）
6. 结束阶段

**加密机制（混合加密）**：
- 对称密钥加密实际数据（AES等高效率加密）
- 非对称算法加密对称密钥（RSA/ECC安全交换）
- 哈希函数保证完整性（SHA-256等）

### HTTPS（HTTP over SSL/TLS）

- HTTP + SSL/TLS = HTTPS
- 提供对Web通信的机密性和完整性保护
- 使用443端口（HTTP为80端口）
- 可有效防御中间人攻击

### IPSec

- **网络层**安全协议，提供端对端安全模式
- 包含两个核心协议：
  - **AH（认证头）**：提供数据完整性验证和来源认证
  - **ESP（封装安全载荷）**：提供加密、完整性验证和认证
- 适用于VPN和站点间安全通信

### PGP（Pretty Good Privacy）

- 用于**电子邮件加密**的应用层安全协议
- 采用**混合加密**：公钥加密会话密钥 + 对称加密邮件内容
- 支持数字签名和消息认证

### 安全协议的层次关系

```
应用层：    PGP（邮件）、S/MIME
传输层：    SSL/TLS、HTTPS
网络层：    IPSec
数据链路层： WPA/WPA2/WPA3（WiFi安全）、802.1X
```
