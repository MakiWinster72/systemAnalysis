# 风险管理

## 概述

风险管理（Risk Management）是识别、评估和应对项目中潜在风险的系统化过程。其目的是最小化风险对项目目标的负面影响，同时抓住风险带来的机会。风险成本包括有形成本（直接损失）、无形成本（减少机会）和预防控制风险的费用。

## 核心内容

### 风险管理的六个步骤

| 步骤 | 核心任务 |
|------|---------|
| **1. 计划编制** | 制定角色职责、预算、风险类别和概率影响定义 |
| **2. 风险识别** | 系统化识别已知和可预测风险（收集资料→估计形势→识别风险） |
| **3. 定性分析** | 评估风险的可能性和影响，确定优先级 |
| **4. 定量分析** | 采用数值方法量化风险影响 |
| **5. 应对计划编制** | 制定针对不同风险的应对策略 |
| **6. 风险监控** | 持续跟踪和评估风险状态 |

### 风险识别方法

- 德尔菲法：多轮匿名专家征询
- 头脑风暴法：团队集体讨论
- SWOT分析：优势、劣势、机会、威胁
- 检查表法：基于历史项目的风险清单
- 因果图（鱼骨图）：分析风险根本原因

### 定量分析方法

| 方法 | 说明 |
|------|------|
| **蒙特卡罗模拟** | 通过大量随机抽样模拟多变量不确定性对结果的影响 |
| **灵敏度分析** | 分析单一因素变化对项目目标的影响程度 |
| **期望货币价值分析（EMV）** | 概率 × 影响 = 期望值 |
| **决策树分析** | 结构化表示决策选项和不确定结果 |

### 风险应对策略

| 策略 | 适用场景 | 方法 |
|------|---------|------|
| **规避** | 高概率高影响风险 | 改变项目计划消除威胁 |
| **转移** | 财务后果严重 | 购买保险、外包 |
| **减轻** | 可降低概率/影响 | 早期测试、冗余设计 |
| **接受** | 低优先级风险 | 应急储备（被动）或制定应急计划（主动） |

### 应急计划与应急储备

- **应急计划**：为特定风险预设的替代方案
- **应急储备**：为已知风险预留的时间或预算缓冲
